Python Flask 資料庫整合教學

讓網站擁有記憶：SQLite 與 MySQL 的 ORM 6 大實戰

為什麼不寫傳統的 SQL 語法？
在現代後端開發中，我們通常使用 ORM (物件關聯對映) 技術。它允許我們使用 Python 的「類別 (Class)」與「物件 (Object)」來操作資料庫，不僅程式碼更簡潔、能防範 SQL 注入攻擊，未來想從 SQLite 切換到 MySQL 甚至 PostgreSQL，都只需要改一行程式碼！

我們將使用 Flask 最強大的資料庫套件 Flask-SQLAlchemy。
請在終端機安裝：pip install Flask-SQLAlchemy PyMySQL

Demo 1 連線設定與建立模型 (Model)

首先，我們要告訴 Flask 資料庫在哪裡（這裡先使用免安裝的 SQLite），並定義資料表長什麼樣子。

app.py
from flask import Flask
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)

# 1. 設定資料庫連線位址 (URI)
# sqlite:/// 代表使用當前目錄下的 test.db 檔案作為資料庫
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///test.db'
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False

# 初始化資料庫物件
db = SQLAlchemy(app)

# 2. 建立資料表模型 (Model)
class User(db.Model):
    id = db.Column(db.Integer, primary_key=True) # 主鍵 (自動遞增)
    username = db.Column(db.String(80), unique=True, nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False)

    def __repr__(self):
        return f"<User {self.username}>"

# 3. 建立實體資料表 (如果 test.db 不存在，會自動產生)
with app.app_context():
    db.create_all()

if __name__ == '__main__':
    app.run(debug=True)

Demo 2 新增資料 (Create)

有了資料表後，我們透過實例化 `User` 類別來產生資料，並丟進 `db.session` 中儲存。

app.py
@app.route('/add_user/<name>/<email>')
def add_user(name, email):
    try:
        # 1. 建立一筆新的 User 物件
        new_user = User(username=name, email=email)
        
        # 2. 將物件加入資料庫會話 (Session) 準備區
        db.session.add(new_user)
        
        # 3. 提交變更，真正寫入資料庫
        db.session.commit()
        return f"成功新增使用者：{name}！"
        
    except Exception as e:
        db.session.rollback() # 發生錯誤時退回，避免資料庫損壞
        return f"新增失敗，可能是帳號或信箱重複了。錯誤：{e}"

測試方法：啟動伺服器後，在瀏覽器輸入 http://127.0.0.1:5000/add_user/Tony/tony@test.com 即可寫入資料。

Demo 3 查詢資料 (Read) 並顯示於網頁

我們可以輕易地抓出「所有使用者」或是「符合特定條件的使用者」，並將他們傳遞給 HTML 模板顯示。

app.py
from flask import render_template_string

@app.route('/users')
def show_users():
    # 取得資料庫中所有的 User (回傳一個 List)
    all_users = User.query.all()
    
    # 條件查詢範例：User.query.filter_by(username='Tony').first()

    # 將資料傳遞給 HTML 渲染
    html_template = """
    <h2>使用者名單</h2>
    <ul>
        {% for u in users %}
            <li>ID: {{ u.id }} | 帳號: {{ u.username }} | 信箱: {{ u.email }}</li>
        {% endfor %}
    </ul>
    """
    return render_template_string(html_template, users=all_users)

Demo 4 更新資料 (Update)

要更新資料，步驟是：先從資料庫「查詢」出該筆資料物件，修改物件的屬性，最後再 `commit()`。

app.py
@app.route('/update_email/<username>/<new_email>')
def update_user(username, new_email):
    # 1. 尋找指定帳號的使用者
    user = User.query.filter_by(username=username).first()
    
    if user:
        # 2. 修改該物件的屬性
        user.email = new_email
        # 3. 提交變更
        db.session.commit()
        return f"使用者 {username} 的信箱已更新為 {new_email}！"
    else:
        return "找不到該使用者。"

Demo 5 刪除資料 (Delete)

與更新類似，找到特定的資料物件後，使用 `db.session.delete()` 將其刪除並提交。

app.py
@app.route('/delete_user/<int:user_id>')
def delete_user(user_id):
    # 利用主鍵 (Primary Key) ID 尋找使用者，找不到會回傳 404 錯誤
    user = User.query.get_or_404(user_id)
    
    try:
        # 將物件從資料庫中刪除
        db.session.delete(user)
        db.session.commit()
        return f"已成功刪除 ID 為 {user_id} 的使用者。"
    except Exception as e:
        db.session.rollback()
        return f"刪除失敗：{e}"

Demo 6 正式上線準備：無痛切換至 MySQL 資料庫

在本地端開發我們常用方便的 SQLite (將資料存在一個本機檔案中)。但當網站要正式上線給幾千人使用時，我們會切換成強大的 MySQL 資料庫伺服器。

得益於 SQLAlchemy ORM，我們完全不用修改前面 Demo 2 ~ 5 的程式碼，只需要更改 Demo 1 的「連線字串 (URI)」即可！

app.py (切換資料庫配置)
# 確保你已經透過 XAMPP 或 Docker 啟動了 MySQL，並建立了一個名為 my_flask_db 的資料庫
# 且已經安裝了連線驅動：pip install PyMySQL

# --- 註解掉原本的 SQLite 設定 ---
# app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///test.db'

# --- 改為 MySQL 的連線字串 ---
# 格式：mysql+pymysql://帳號:密碼@主機位置:Port/資料庫名稱
app.config['SQLALCHEMY_DATABASE_URI'] = 'mysql+pymysql://root:123456@localhost:3306/my_flask_db'

# 重新執行程式後，Flask 就會自動在你的 MySQL 裡建立好資料表囉！
