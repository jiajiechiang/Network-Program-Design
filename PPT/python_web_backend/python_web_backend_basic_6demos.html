Python 網頁後端基礎教學

從零開始架設網站：伺服器、路由、靜態檔案與 API 的 6 大實戰

什麼是網頁後端？
後端 (Backend) 就像是餐廳的廚房，負責接收客人 (瀏覽器) 的點單 (Request)，處理食材 (資料庫邏輯)，最後把餐點 (HTML 或 JSON) 送回給客人 (Response)。

我們將使用 Python 最經典的輕量級後端框架 Flask 來實作。請在終端機輸入：pip install Flask

Demo 1 啟動伺服器與基礎路由 (Routing)

架設網站的第一步是啟動一台伺服器，並告訴伺服器當使用者輸入特定網址 (例如 "/") 時，應該回傳什麼內容給他。

app_basic.py
from flask import Flask

# 初始化後端應用程式
app = Flask(__name__)

# 建立路由：當使用者造訪根目錄 '/' 時，觸發此函式
@app.route('/')
def home():
    return "歡迎來到我的 Python 後端網站！"

if __name__ == '__main__':
    # 啟動伺服器，port 預設為 5000
    app.run(debug=True)

Demo 2 動態網址與 URL 參數

實務上我們不可能為每一個使用者寫一個路由。透過動態路由，我們可以捕捉網址中的變數，並交由 Python 處理。

app_dynamic.py
from flask import Flask

app = Flask(__name__)

# 捕捉字串：<username> 將作為參數傳入函式
@app.route('/profile/<username>')
def user_profile(username):
    return f"這是 {username} 的個人首頁"

# 捕捉整數：<int:product_id>，確保傳入的是數字格式
@app.route('/item/<int:product_id>')
def show_item(product_id):
    return f"您正在查看商品編號：{product_id}"

if __name__ == '__main__':
    app.run(debug=True)

Demo 3 後端與前端結合：回傳 HTML 網頁

後端不只回傳純文字，還能把寫好的 HTML 網頁丟給瀏覽器。我們使用 render_template 將 Python 變數傳入 HTML 中動態顯示。

app_template.py
from flask import Flask, render_template

app = Flask(__name__)

@app.route('/')
def index():
    # 將變數 name 傳遞給 index.html
    return render_template('index.html', name="Python 新手")
templates/index.html (必須放在 templates 資料夾下)
<!DOCTYPE html>
<html>
<body>
    <h1>哈囉，{{ name }}！</h1>
    <p>這是由 Python 後端產生出來的網頁。</p>
</body>
</html>

Demo 4 提供靜態檔案 (CSS, JS, 圖片)

網頁需要排版與圖片。在後端框架中，靜態檔案不能隨便放，必須放在名為 static 的資料夾中，並透過特殊的網址來載入。

templates/style_demo.html
<!DOCTYPE html>
<html>
<head>
    <!-- 使用 url_for 動態生成靜態檔案的網址 -->
    <link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">
</head>
<body>
    <h2>載入靜態資源範例</h2>
    <!-- 載入 static/images/logo.png -->
    <img src="{{ url_for('static', filename='images/logo.png') }}">
</body>
</html>

Demo 5 接收前端資料：處理 GET 與 POST 表單

當使用者填寫登入表單或搜尋框時，資料會傳給後端。GET 用於一般查詢 (資料在網址上)，POST 用於隱密提交 (如密碼)。

app_form.py
from flask import Flask, request, render_template

app = Flask(__name__)

# 允許這個路由接收 GET 與 POST 請求
@app.route('/login', methods=['GET', 'POST'])
def login():
    if request.method == 'POST':
        # 處理前端傳來的 POST 表單資料
        user_account = request.form.get('account')
        user_pwd = request.form.get('password')
        return f"後端已收到帳號：{user_account}，密碼：{user_pwd}"
    
    # 如果是 GET 請求，就回傳一個登入表單網頁給他
    return """
        <form method="POST">
            帳號: <input type="text" name="account"><br>
            密碼: <input type="password" name="password"><br>
            <input type="submit" value="登入">
        </form>
    """

Demo 6 打造 RESTful API：回傳 JSON 資料

現代網頁很多是「前後端分離」(例如前端用 React/Vue，手機用 iOS App)。後端不再回傳 HTML，而是回傳純資料 JSON 格式，這種服務稱為 API。

app_api.py
from flask import Flask, jsonify

app = Flask(__name__)

# 模擬資料庫裡的資料
users_db = [
    {"id": 1, "name": "Alice", "role": "Admin"},
    {"id": 2, "name": "Bob", "role": "User"}
]

@app.route('/api/users')
def get_users_api():
    # 使用 jsonify 將 Python 字典轉換成標準的 JSON 格式回傳
    return jsonify({
        "status": "success",
        "total_count": len(users_db),
        "data": users_db
    })

if __name__ == '__main__':
    app.run(debug=True)
