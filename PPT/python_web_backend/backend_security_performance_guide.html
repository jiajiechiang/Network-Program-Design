Python 後端開發專題指南

深度解析：安全性防護 (JWT/Bcrypt) 與高效能優化 (Redis/Celery)

專題核心方向：
當網站從小型個人專案轉為企業級規模時，「資安」與「效能」是決定系統生死的兩大關鍵。
本份教學將帶領您完整打通 JWT/Bcrypt 安全防線，以及透過 Redis/Celery 實現十倍效能飆升的架構設計。

Part 1 安全性核心：Bcrypt 密碼雜湊與 JWT 權限驗證

在資安防護中，我們必須遵循兩個黃金原則：密碼絕對不能明文儲存 [cite: 21]，且 API 存取必須具備無狀態 (Stateless) 身分驗證 [cite: 21]。以下透過兩個實戰範例展現 Flask 中的具體實作。

Demo 1：使用 Flask-Bcrypt 進行安全的密碼加鹽雜湊

security_bcrypt.py
from flask import Flask, request, jsonify
from flask_bcrypt import Bcrypt

app = Flask(__name__)
bcrypt = Bcrypt(app)

# 模擬資料庫
user_database = {}

@app.route('/api/register', methods=['POST'])
def register():
    data = request.json
    username = data.get('username')
    password = data.get('password')
    
    # 使用 Bcrypt 產生雜湊密碼 (自動加鹽，抗彩虹表攻擊)
    hashed_pwd = bcrypt.generate_password_hash(password).decode('utf-8')
    user_database[username] = hashed_pwd
    
    return jsonify({"message": "註冊成功，密碼已受 Bcrypt 保護！"})

@app.route('/api/login', methods=['POST'])
def login():
    data = request.json
    username = data.get('username')
    password = data.get('password')
    
    stored_hash = user_database.get(username)
    # 比對輸入的明文密碼與資料庫中的雜湊密碼是否相符
    if stored_hash and bcrypt.check_password_hash(stored_hash, password):
        return jsonify({"message": "登入成功！"})
    
    return jsonify({"error": "帳號或密碼錯誤"}), 401

Demo 2：使用 Flask-JWT-Extended 簽發與驗證 Token

security_jwt.py
from flask import Flask, request, jsonify
from flask_jwt_extended import (
    FlaskJWTExtended, create_access_token, jwt_required, get_jwt_identity
)

app = Flask(__name__)
app.config['JWT_SECRET_KEY'] = 'your-very-secure-secret-key'
jwt = FlaskJWTExtended(app)

@app.route('/api/token', methods=['POST'])
def create_token():
    username = request.json.get('username')
    # 假設帳密驗證通過，發放一串具有時效性的 JWT 數位通行證
    if username == 'admin':
        access_token = create_access_token(identity=username)
        return jsonify(access_token=access_token)
    return jsonify({"error": "無效的使用者"}), 401

@app.route('/api/dashboard', methods=['GET'])
@jwt_required() # 必須在 Header 帶上 Authorization: Bearer <token> 才能訪問
def dashboard():
    current_user = get_jwt_identity() # 從 Token 中解碼出使用者身分
    return jsonify({"user": current_user, "data": "這是高度機密的後台數據"})

Part 2 效能優化核心：Redis 快取快篩與 Celery 非同步任務

當網站面臨大量並行請求時，必須透過 Redis 將熱門資料暫存於記憶體 [cite: 21]，並將耗時任務（如寄信、寫檔、大數據運算）交給 Celery 丟到背景非同步執行 [cite: 21]，確保主執行緒永不阻塞。

Demo 3：利用 Redis 實作 API 查詢結果快取

performance_redis.py
from flask import Flask, jsonify
import redis
import time

app = Flask(__name__)
# 連線至本地端 Redis 伺服器
r = redis.Redis(host='localhost', port=6379, db=0)

@app.route('/api/reports')
def get_reports():
    cache_key = "monthly_sales_report"
    
    # 1. 優先向 Redis 查詢是否有快取資料
    cached_result = r.get(cache_key)
    if cached_result:
        return jsonify({"source": "Redis Cache (秒回)", "data": cached_result.decode()})
        
    # 2. 若無快取，執行耗時的資料庫複雜查詢或運算 (模擬耗時 3 秒)
    time.sleep(3)
    heavy_data = "2026年Q1全球銷售總額報表數據..."
    
    # 3. 將計算結果寫入 Redis，並設定 120 秒後自動過期失效
    r.setex(cache_key, 120, heavy_data)
    
    return jsonify({"source": "Database Calculation", "data": heavy_data})

優化效益：第一次查詢需要等待 3 秒，但接下來 2 分鐘內的所有訪客造訪此 API，都會在 0.01 秒內從 Redis 記憶體直接取得結果！

Demo 4：利用 Celery 實作耗時任務背景非同步執行

performance_celery.py (Worker 任務定義)
from celery import Celery
import time

# 初始化 Celery 引擎，使用 Redis 作為訊息佇列 (Broker)
celery_app = Celery(
    'tasks',
    broker='redis://localhost:6379/0',
    backend='redis://localhost:6379/0'
)

@celery_app.task
def send_welcome_email_task(user_email):
    print(f"[{user_email}] 開始在背景執行寄信程序...")
    time.sleep(5) # 模擬耗時的第三方 SMTP 寄信動作
    print(f"[{user_email}] 驗證信件已成功寄出！")
    return "Email Sent"
app_trigger.py (Flask 端觸發)
from flask import Flask, jsonify
from performance_celery import send_welcome_email_task

app = Flask(__name__)

@app.route('/api/register-user', methods=['POST'])
def register():
    # ... 執行使用者寫入資料庫的邏輯 ...
    target_email = "vip_user@example.com"
    
    # 關鍵：使用 .delay() 丟進任務佇列，Flask 會「毫秒級」直接回傳 Response 給客戶端
    # 實際的 5 秒寄信工作交給背後的 Celery Worker 非同步默默處理！
    send_welcome_email_task.delay(target_email)
    
    return jsonify({"message": "註冊成功！系統已在背景為您發送歡迎信。"})
