Demo 1 Jinja2 模板繼承 (Template Inheritance)

每個網頁都有共同的導覽列 (Navbar) 與頁尾 (Footer)。使用「模板繼承」就能把共同部分寫在 base.html，其他頁面只需填入不同內容。

templates/base.html (父模板)
<!DOCTYPE html>
<html>
<head>
    <title>我的中階網站</title>
</head>
<body>
    <nav><a href="/">首頁</a> | <a href="/about">關於我們</a></nav>
    <hr>
    
    <!-- 挖出一個名為 content 的洞，讓子模板來填補 -->
    {% block content %}{% endblock %}
    
    <hr>
    <footer>版權所有 © 2026</footer>
</body>
</html>
templates/index.html (子模板)
<!-- 宣告繼承 base.html -->
{% extends "base.html" %}

<!-- 將內容填入 content 區塊 -->
{% block content %}
    <h2>這裡是首頁內容</h2>
    <p>這段文字會自動被放入 base.html 的中間！</p>
{% endblock %}

Demo 2 表單驗證與 CSRF 防護 (Flask-WTF)

手刻 HTML 表單很容易有安全漏洞 (如 CSRF 攻擊)。使用 Flask-WTF 可以用 Python 類別定義表單，並自動進行嚴格的格式驗證與安全防護。

forms.py
from flask_wtf import FlaskForm
from wtforms import StringField, PasswordField, SubmitField
from wtforms.validators import DataRequired, Length

class LoginForm(FlaskForm):
    # 定義帳號欄位，設定必填 (DataRequired) 與長度限制
    username = StringField('帳號', validators=[DataRequired(), Length(min=4, max=20)])
    password = PasswordField('密碼', validators=[DataRequired()])
    submit = SubmitField('登入')
app.py
from flask import Flask, render_template
from forms import LoginForm

app = Flask(__name__)
app.config['SECRET_KEY'] = 'your_secret_key_here' # WTF 表單需要密鑰防護

@app.route('/login', methods=['GET', 'POST'])
def login():
    form = LoginForm()
    if form.validate_on_submit(): # 若是 POST 且通過所有驗證
        user = form.username.data
        return f"歡迎登入，{user}！"
    return render_template('login.html', form=form)

Demo 3 使用者登入狀態管理 (Session)

HTTP 協定本身沒有記憶功能。為了記住「使用者已登入」，後端會將資訊存入 session 字典，Flask 會自動將其加密並存在使用者的瀏覽器 Cookie 中。

app_session.py
from flask import Flask, session, redirect, url_for, request

app = Flask(__name__)
app.secret_key = 'super_secret_key' # Session 必須要有 secret_key 進行加密

@app.route('/login', methods=['POST'])
def login():
    # 假設帳密驗證成功，將使用者名稱存入 session
    session['username'] = request.form.get('username')
    return redirect(url_for('dashboard'))

@app.route('/dashboard')
def dashboard():
    # 檢查 session 中是否有 username，判斷是否登入
    if 'username' in session:
        return f"這是你的專屬後台，{session['username']}！"
    return "請先登入！", 401

@app.route('/logout')
def logout():
    # 登出就是把資料從 session 中移除
    session.pop('username', None)
    return "已成功登出。"

Demo 4 資料庫關聯：一對多 (One-to-Many)

在進階的資料庫設計中，資料表通常會互相「關聯」。例如：一個「使用者 (User)」可以擁有「多篇文章 (Post)」。

models.py (搭配 Flask-SQLAlchemy)
from flask_sqlalchemy import SQLAlchemy

db = SQLAlchemy()

class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), nullable=False)
    # 建立關聯 (一對多)，backref 讓 Post 可以反向查出作者
    posts = db.relationship('Post', backref='author', lazy=True)

class Post(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    title = db.Column(db.String(120), nullable=False)
    # 外鍵 (Foreign Key)，連結到 user 資料表的 id 欄位
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'), nullable=False)

# 使用方式範例：
# author = User.query.first()
# 取得該作者所有文章：author.posts
# 取得某篇文章的作者：post.author.username

Demo 5 安全的檔案上傳 (File Upload)

接收使用者上傳的圖片或文件，我們必須使用 secure_filename 過濾檔名，避免駭客透過檔名漏洞 (如 `../../../script.sh`) 攻擊伺服器。

app_upload.py
import os
from flask import Flask, request
from werkzeug.utils import secure_filename

app = Flask(__name__)
app.config['UPLOAD_FOLDER'] = './uploads' # 設定上傳目錄
os.makedirs(app.config['UPLOAD_FOLDER'], exist_ok=True)

@app.route('/upload', methods=['POST'])
def upload_file():
    # 從表單接收名為 'file' 的檔案
    if 'file' not in request.files:
        return '沒有上傳檔案'
        
    file = request.files['file']
    if file.filename != '':
        # 將中文或危險字元過濾，確保檔名安全
        safe_name = secure_filename(file.filename)
        save_path = os.path.join(app.config['UPLOAD_FOLDER'], safe_name)
        
        file.save(save_path) # 將檔案存入伺服器硬碟
        return f"檔案 {safe_name} 上傳成功！"

Demo 6 藍圖 (Blueprints)：大型專案模組化

如果把所有路由 (Route) 都寫在同一個 app.py 裡，程式碼會變得難以維護。Blueprint 允許我們將後端拆分成「會員模組」、「購物車模組」等不同檔案。

auth_bp.py (會員模組)
from flask import Blueprint

# 建立 Blueprint 實例，url_prefix 讓這個模組下的路由都會自動加上 /auth 前綴
auth = Blueprint('auth', __name__, url_prefix='/auth')

@auth.route('/login')
def login():
    return "這裡是會員登入頁面 (實際網址為 /auth/login)"
app.py (主程式)
from flask import Flask
from auth_bp import auth # 匯入寫好的藍圖

app = Flask(__name__)

# 將藍圖註冊到主程式中
app.register_blueprint(auth)

if __name__ == '__main__':
    app.run()
