Python Django 基礎教學

功能完整的全端 Web 框架：建立網站與 API 的 6 大核心範例

Django 環境建置與觀念：
Django 是一個重量級的 MTV (Model-Template-View) 框架，內建資料庫管理、後台、安全機制，非常適合開發完整的企業級網站。

安裝指令：pip install django

Demo 1 建立專案與啟動伺服器

Django 有著嚴謹的目錄結構，我們必須透過指令來產生專案架構，並建立我們第一個應用程式 (App)。

1. 在終端機執行以下指令：

# 建立名為 myproject 的主專案
django-admin startproject myproject

# 進入專案資料夾
cd myproject

# 建立一個名為 myapp 的應用程式模組
python manage.py startapp myapp

2. 註冊 App 到主專案中：

打開 myproject/settings.py，找到 INSTALLED_APPS 並加入 'myapp'。

myproject/settings.py
INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    # 加入我們剛剛建立的 app
    'myapp', 
]

3. 啟動測試伺服器：

python manage.py runserver

打開瀏覽器造訪 http://127.0.0.1:8000/，看到火箭起飛畫面即代表成功！

Demo 2 第一個視圖與路由 (View & URL)

在 Django 中，網址是由 urls.py 負責分配，而邏輯處理是由 views.py 負責。

1. 撰寫 View (視圖邏輯)

myapp/views.py
from django.shortcuts import render
from django.http import HttpResponse

def hello_world(request):
    # 接收使用者的 request，回傳一段簡單的 HTML 字串
    return HttpResponse("<h1>Hello Django! 這是我的第一個視圖</h1>")

2. 設定 URL 路由

將網址 /hello/ 對應到剛剛寫的 hello_world 函式。

myproject/urls.py
from django.contrib import admin
from django.urls import path
from myapp import views # 匯入 myapp 的 views

urlpatterns = [
    path('admin/', admin.site.urls),
    # 設定路由，造訪 /hello/ 時執行 views.hello_world
    path('hello/', views.hello_world),
]

Demo 3 模板渲染 (Templates)

實務上我們不會在 Python 檔案裡寫 HTML，而是使用 render 將變數傳遞給獨立的 HTML 模板檔案。

1. 建立模板檔案

在 myapp 資料夾內建立 templates/myapp/ 資料夾，並新增 index.html。

myapp/templates/myapp/index.html
<!-- 使用雙大括號 {{ }} 顯示後端傳來的變數 -->
<h1>歡迎，{{ user_name }}！</h1>
<p>您目前有 {{ messages_count }} 則新通知。</p>

2. 撰寫 View

myapp/views.py
def index_page(request):
    # 準備要傳給 HTML 的資料字典 (Context)
    context_data = {
        "user_name": "Tony",
        "messages_count": 5
    }
    # 使用 render 渲染模板，並把 context_data 傳過去
    return render(request, 'myapp/index.html', context_data)

(記得要在 urls.py 加上 path('index/', views.index_page) 喔！)

Demo 4 資料庫模型與內建後台 (Models & Admin)

Django 的殺手級功能：用 Python 寫 Class 就能建立資料表，還自動送你一個強大的管理後台！

1. 定義資料表模型 (Model)

myapp/models.py
from django.db import models

class Article(models.Model):
    # 定義文章標題 (最大長度 100)
    title = models.CharField(max_length=100)
    # 定義文章內容 (長文本)
    content = models.TextField()
    # 建立時間 (自動記錄當下時間)
    created_at = models.DateTimeField(auto_now_add=True)

    def __str__(self):
        return self.title # 在後台顯示文章標題

2. 執行資料庫遷移 (Migrations)

在終端機執行以下指令，讓 Django 幫你自動建立 SQLite 資料表：

python manage.py makemigrations
python manage.py migrate

3. 註冊到後台並建立超級管理員

myapp/admin.py
from django.contrib import admin
from .models import Article

# 註冊模型，讓它出現在 Django 管理後台
admin.site.register(Article)

在終端機輸入 python manage.py createsuperuser 建立帳號，然後造訪 http://127.0.0.1:8000/admin/ 即可登入新增文章！

Demo 5 查詢資料庫並顯示在網頁

我們要把剛剛在後台新增的文章，抓出來並顯示在前端網頁上。

1. 撰寫 View (讀取資料庫)

myapp/views.py
from django.shortcuts import render
from .models import Article

def article_list(request):
    # 使用 ORM 語法取得資料庫中所有的文章，並依照時間新到舊排序
    articles = Article.objects.all().order_by('-created_at')
    
    return render(request, 'myapp/article_list.html', {'articles': articles})

2. 撰寫 Template (顯示資料)

myapp/templates/myapp/article_list.html
<h2>最新文章列表</h2>
<ul>
    <!-- 使用 Django 模板標籤迴圈印出文章 -->
    {% for article in articles %}
        <li>
            <h3>{{ article.title }}</h3>
            <p>{{ article.content }}</p>
            <small>發布時間：{{ article.created_at }}</small>
        </li>
    {% endfor %}
</ul>

Demo 6 建立基礎 JSON API (API 教學)

除了回傳 HTML 網頁，現代後端最重要的工作是提供 API 給前端 (Vue/React) 或手機 App 呼叫。在不使用額外套件的情況下，我們可以使用 Django 內建的 JsonResponse 來達成。

myapp/views.py
from django.http import JsonResponse
from .models import Article

def api_article_list(request):
    # 取得所有文章
    articles = Article.objects.all()
    
    # 將 Django Model 物件轉換為 Python 字典列表
    data_list = []
    for a in articles:
        data_list.append({
            "id": a.id,
            "title": a.title,
            "content": a.content,
            "created_at": a.created_at.strftime("%Y-%m-%d %H:%M:%S")
        })
        
    # 回傳 JSON 格式的 HTTP Response
    return JsonResponse({
        "status": "success",
        "total": len(data_list),
        "data": data_list
    }, safe=False)

(在 urls.py 加上 path('api/articles/', views.api_article_list)，打開瀏覽器就能看到 JSON 格式的資料囉！)
