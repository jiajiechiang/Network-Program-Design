Demo 1 Django Forms：自動生成與驗證表單

不需手寫繁瑣的 HTML 表單！Django 提供 ModelForm，可以直接把資料庫模型轉換成安全的網頁表單，並自動進行資料驗證 (例如：防範空白、格式錯誤)。

myapp/forms.py
from django import forms
from .models import Article

# 建立綁定 Model 的表單
class ArticleForm(forms.ModelForm):
    class Meta:
        model = Article
        fields = ['title', 'content'] # 允許使用者輸入的欄位
myapp/views.py
from django.shortcuts import render, redirect
from .forms import ArticleForm

def create_article(request):
    if request.method == "POST":
        # 將 POST 傳來的資料交給 Form 綁定
        form = ArticleForm(request.POST)
        if form.is_valid(): # 通過安全與格式驗證
            form.save()     # 自動存入資料庫
            return redirect('article_list')
    else:
        # GET 請求：產生空表單
        form = ArticleForm()
        
    return render(request, 'myapp/create_article.html', {'form': form})
myapp/templates/myapp/create_article.html
<form method="POST">
    <!-- 必須加入 CSRF Token 防止跨站攻擊 -->
    {% csrf_token %}
    <!-- form.as_p 會自動把表單渲染成 <p> 標籤包覆的 HTML -->
    {{ form.as_p }}
    <button type="submit">發布文章</button>
</form>

Demo 2 權限與驗證：需要登入才能訪問的頁面

Django 內建了完整的 Auth 系統。我們可以使用簡單的裝飾器 (Decorator) 輕鬆鎖住某些頁面，限制只有登入的使用者能觀看或操作。

myapp/views.py
from django.contrib.auth.decorators import login_required
from django.shortcuts import render

# 加上這個裝飾器，未登入者會被自動導向 settings.LOGIN_URL 指定的登入頁面
@login_required
def dashboard(request):
    # 可以透過 request.user 取得目前登入的使用者物件
    context = {
        'username': request.user.username,
        'email': request.user.email
    }
    return render(request, 'myapp/dashboard.html', context)

Demo 3 Class-Based Views (CBV)：類別視圖

當你在寫「顯示列表」、「顯示單一內容」時，邏輯通常很固定。Django 提供了 ListView 和 DetailView 等類別視圖，能大幅減少重複的程式碼。

myapp/views.py
from django.views.generic import ListView, DetailView
from .models import Article

# 取代原本寫了好幾行的 article_list 函式
class ArticleListView(ListView):
    model = Article
    template_name = 'myapp/article_list.html'
    context_object_name = 'articles'
    ordering = ['-created_at'] # 新到舊排序

# 自動處理根據 PK 抓取單筆文章的邏輯
class ArticleDetailView(DetailView):
    model = Article
    template_name = 'myapp/article_detail.html'
    context_object_name = 'article'

注意：在 urls.py 中綁定時，寫法要改為 path('articles/', views.ArticleListView.as_view())。

Demo 4 進階 ORM 查詢：Q 物件與搜尋功能

當我們想做網站的「搜尋引擎」時，需要使用 filter 搭配 `__icontains`，若要達成 "OR" 條件 (例如標題或內容包含關鍵字)，則必須引進 Q 物件。

myapp/views.py
from django.shortcuts import render
from django.db.models import Q
from .models import Article

def search_articles(request):
    # 取得網址列上的 ?q=關鍵字
    query = request.GET.get('q', '')
    
    if query:
        # 尋找 標題(title) 或 內容(content) 包含關鍵字的文章，icontains 代表不分大小寫
        results = Article.objects.filter(
            Q(title__icontains=query) | Q(content__icontains=query)
        )
    else:
        results = Article.objects.none() # 沒輸入關鍵字就回傳空
        
    return render(request, 'myapp/search.html', {'results': results, 'query': query})

Demo 5 導入 DRF：強大的 Serializers (序列化)

在基礎篇我們手動將 Model 轉成字典再轉 JSON。使用 Django REST Framework (DRF)，Serializer 會自動幫我們把 Model 轉換成標準的 JSON 格式。

myapp/serializers.py (需手動新增此檔案)
from rest_framework import serializers
from .models import Article

class ArticleSerializer(serializers.ModelSerializer):
    class Meta:
        model = Article
        # '__all__' 代表將所有欄位轉換為 JSON
        fields = '__all__'

Demo 6 打造專業 RESTful API 介面

結合剛剛寫好的 Serializer，我們利用 DRF 的 @api_view 裝飾器，輕鬆完成支援 GET 與 POST 的現代化 API 節點，DRF 還會附贈一個漂亮的 API 測試網頁！

myapp/views.py
from rest_framework.decorators import api_view
from rest_framework.response import Response
from rest_framework import status
from .models import Article
from .serializers import ArticleSerializer

@api_view(['GET', 'POST'])
def article_api(request):
    if request.method == 'GET':
        # 1. 抓取所有文章
        articles = Article.objects.all()
        # 2. 透過 Serializer 轉換為 JSON 格式 (many=True 代表這是一個列表)
        serializer = ArticleSerializer(articles, many=True)
        return Response(serializer.data)
        
    elif request.method == 'POST':
        # 1. 將前端送來的 JSON 放入 Serializer 解析
        serializer = ArticleSerializer(data=request.data)
        # 2. 如果資料格式正確，自動存入資料庫
        if serializer.is_valid():
            serializer.save()
            # 回傳成功狀態碼 201 Created
            return Response(serializer.data, status=status.HTTP_201_CREATED)
        # 失敗則回傳 400 Bad Request 以及錯誤原因
        return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)
