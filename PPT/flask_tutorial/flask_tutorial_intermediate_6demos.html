Python Flask 中階教學指南

涵蓋 Jinja2 模板、表單處理與靜態資源的 6 大實戰範例

Demo 1 基礎變數傳遞與渲染 (Jinja2)

Flask 使用 Jinja2 作為模板引擎。你可以輕鬆地將 Python 變數傳到 HTML 中顯示。

app.py
from flask import Flask, render_template

app = Flask(__name__)

@app.route('/')
def index():
    # 將字串與整數傳遞給 HTML
    return render_template('index.html', user_name="Alice", unread_count=5)
templates/index.html
<h1>歡迎，{{ user_name }}！</h1>
<p>您目前有 {{ unread_count }} 則未讀訊息。</p>

Demo 2 條件判斷與迴圈 (If / For)

在 HTML 裡面也能寫程式邏輯！利用 {% if %} 和 {% for %} 動態產生網頁內容。

app.py
@app.route('/products')
def products():
    # 準備一個字典列表
    item_list = [
        {'name': '筆記型電腦', 'price': 30000, 'in_stock': True},
        {'name': '無線滑鼠', 'price': 800, 'in_stock': False},
        {'name': '機械鍵盤', 'price': 2500, 'in_stock': True}
    ]
    return render_template('products.html', items=item_list)
templates/products.html
<h2>產品列表</h2>
<ul>
    {% for item in items %}
        <li>
            {{ item.name }} - ${{ item.price }}
            {% if item.in_stock %}
                <span style="color: green;">(有現貨)</span>
            {% else %}
                <span style="color: red;">(已售完)</span>
            {% endif %}
        </li>
    {% endfor %}
</ul>

Demo 3 模板繼承 (Template Inheritance)

每個網頁都有共同的導覽列 (Navbar) 和頁尾 (Footer)。使用「模板繼承」可以避免重複寫相同的 HTML 程式碼。

templates/base.html (父模板)
<!DOCTYPE html>
<html>
<head>
    <title>我的網站</title>
</head>
<body>
    <nav>這是一共用的導覽列</nav>
    
    <hr>
    <!-- 定義一個名為 content 的區塊，讓子模板填入內容 -->
    {% block content %}{% endblock %}
    <hr>
    
    <footer>版權所有 © 2026</footer>
</body>
</html>
templates/about.html (子模板)
<!-- 繼承 base.html -->
{% extends "base.html" %}

<!-- 覆寫 content 區塊 -->
{% block content %}
    <h2>關於我們</h2>
    <p>這裡的內容會自動被放入 base.html 的中間！</p>
{% endblock %}

Demo 4 載入靜態檔案 (CSS / 圖片)

在 Flask 中，CSS、JS 或圖片不能直接使用相對路徑，必須使用 url_for 函式來產生正確的靜態檔案網址。

templates/style_demo.html
<head>
    <!-- 載入 static 資料夾下的 style.css -->
    <link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">
</head>
<body>
    <!-- 載入 static/images 資料夾下的 logo.png -->
    <img src="{{ url_for('static', filename='images/logo.png') }}" alt="Logo">
</body>

Demo 5 處理表單傳送 (GET 與 POST)

網頁前後端互動的核心。GET 用於取得頁面，POST 用於提交敏感或大量資料（如登入、填寫問卷）。

app.py
from flask import request

# 允許這個路由處理 GET 與 POST 方法
@app.route('/login', methods=['GET', 'POST'])
def login():
    if request.method == 'POST':
        # 抓取表單中 name 屬性為 username 和 password 的值
        user = request.form.get('username')
        pwd = request.form.get('password')
        
        if user == 'admin' and pwd == '1234':
            return "登入成功！"
        else:
            return "帳號或密碼錯誤。"
            
    # 如果是 GET 請求，就回傳登入表單頁面
    return render_template('login.html')
templates/login.html
<!-- method 設為 POST -->
<form method="POST" action="/login">
    帳號: <input type="text" name="username"><br>
    密碼: <input type="password" name="password"><br>
    <button type="submit">登入</button>
</form>

Demo 6 快閃訊息提示 (Flash Messages)

在使用者操作成功或失敗後（例如密碼錯誤），在下一個頁面顯示一次性的提示訊息。這需要設定 secret_key 來啟用 Session 功能。

app.py
from flask import flash, redirect, url_for

# 使用 flash 必須設定 secret_key 進行加密
app.secret_key = 'my_secret_key_123'

@app.route('/submit', methods=['POST'])
def submit():
    # 假設處理了一些資料...
    # 發送成功訊息 (第二個參數 'success' 是訊息類別)
    flash('資料已成功送出！', 'success')
    
    # 重新導向回首頁
    return redirect(url_for('index'))
templates/index.html (接收端)
<!-- 在頁面頂部擷取所有 flash 訊息 -->
{% with messages = get_flashed_messages(with_categories=true) %}
  {% if messages %}
    <ul class="flashes">
    {% for category, message in messages %}
      <!-- 根據 category 設定不同的 CSS class -->
      <li class="{{ category }}">{{ message }}</li>
    {% endfor %}
    </ul>
  {% endif %}
{% endwith %}
