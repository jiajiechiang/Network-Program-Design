Python Flask 中階教學指南

網頁模板 (Jinja2) 與 表單處理 (GET/POST)

專案資料夾結構 (重要概念)

觀念解析： 當我們要回傳完整的 HTML 網頁時，將 HTML 程式碼直接寫在 Python 檔中會非常雜亂。Flask 預設使用 Jinja2 模板引擎，並會自動到特定的資料夾尋找資源。

請在您的專案根目錄下，建立以下的資料夾結構：

my_flask_app/ │ ├── app.py (你的主要 Python 程式檔) ├── templates/ (必須叫這個名字！用來放 HTML 模板) │ ├── index.html │ └── result.html └── static/ (必須叫這個名字！用來放 CSS, JS, 圖片) └── style.css

實作範例一：使用 Jinja2 渲染 HTML 模板

Jinja2 允許我們將 Python 變數傳遞到 HTML 中，並且可以在 HTML 裡面使用迴圈和條件判斷。

1. 撰寫 app.py

from flask import Flask, render_template

app = Flask(__name__)

@app.route('/')
def home():
    # 準備要傳遞給 HTML 的資料
    user_name = 'Tony'
    hobbies = ['閱讀', '寫程式', '爬山']
    
    # render_template 會去 templates 資料夾找 index.html
    # 並將變數 name 和 hobbies 傳過去
    return render_template('index.html', name=user_name, hobbies=hobbies)

if __name__ == '__main__':
    app.run(debug=True)

2. 撰寫 templates/index.html

在 HTML 中，使用 {{ 變數名稱 }} 顯示變數，使用 {% 指令 %} 執行迴圈或條件判斷。

<!DOCTYPE html>
<html lang="zh-TW">
<head>
    <meta charset="UTF-8">
    <title>首頁</title>
</head>
<body>
    <h1>哈囉，{{ name }}！歡迎來到首頁。</h1>
    
    <h3>我的興趣列表：</h3>
    <ul>
        <!-- 使用 Jinja2 的 for 迴圈 -->
        {% for hobby in hobbies %}
            <li>{{ hobby }}</li>
        {% endfor %}
    </ul>
</body>
</html>

實作範例二：表單處理 (GET 與 POST 請求)

重要觀念：
- GET 請求： 預設的網頁請求方式，通常用來「取得」資料（例如載入網頁）。表單若用 GET，資料會顯示在網址列。
- POST 請求： 用來「提交」資料（例如登入帳號、送出留言）。資料不會顯示在網址列，較為安全。

1. 修改 app.py 加入表單路由

我們需要從 flask 匯入 request 物件來接收前端傳來的資料。

from flask import Flask, render_template, request

app = Flask(__name__)

# 允許這個路由接收 GET 與 POST 請求
@app.route('/login', methods=['GET', 'POST'])
def login():
    if request.method == 'POST':
        # 如果是 POST 請求，代表使用者送出了表單
        # 使用 request.form.get('HTML中的name屬性') 取得資料
        account = request.form.get('account')
        password = request.form.get('password')
        
        return render_template('result.html', account=account, pwd=password)
    
    else:
        # 如果是 GET 請求，代表使用者剛連進這個網址，我們顯示登入表單給他
        return render_template('login.html')

if __name__ == '__main__':
    app.run(debug=True)

2. 建立 templates/login.html (表單頁面)

<!DOCTYPE html>
<html>
<body>
    <h2>會員登入系統</h2>
    <!-- form 的 action 指定要傳送的網址，method 指定使用 POST -->
    <form action="/login" method="POST">
        <label>帳號：</label>
        <!-- 這裡的 name 屬性非常重要，後端就是靠它來抓資料 -->
        <input type="text" name="account" required> <br><br>
        
        <label>密碼：</label>
        <input type="password" name="password" required> <br><br>
        
        <input type="submit" value="登入">
    </form>
</body>
</html>

3. 建立 templates/result.html (結果頁面)

<!DOCTYPE html>
<html>
<body>
    <h2>登入結果</h2>
    <p>您輸入的帳號是：<strong>{{ account }}</strong></p>
    <p>您輸入的密碼是：<strong>{{ pwd }}</strong></p>
    <br>
    <a href="/login">返回登入頁</a>
</body>
</html>

如何測試？

  1. 執行 python app.py。
  2. 開啟瀏覽器前往 http://127.0.0.1:5000/login，這時觸發的是 GET 請求，你會看到登入表單。
  3. 在表單中輸入帳號與密碼，點擊「登入」。
  4. 這時網頁會發送 POST 請求，Flask 接收到資料後，會將資料傳遞給 result.html 顯示出來！
