Demo 1 建立 RESTful API (回傳 JSON)

在現代網頁開發中，後端通常不需要負責渲染 HTML，而是作為 API 伺服器，將資料以 JSON 格式傳遞給前端（如 React, Vue, 或手機 App）。Flask 提供了 jsonify 來輕鬆達成。

app_api.py
from flask import Flask, jsonify, request

app = Flask(__name__)

# 模擬資料庫資料
users_db = [
    {"id": 1, "name": "Alice", "role": "Admin"},
    {"id": 2, "name": "Bob", "role": "User"}
]

@app.route('/api/users', methods=['GET'])
def get_users():
    # 將 Python 字典或列表轉換為 JSON 格式並加上正確的 HTTP Header
    return jsonify({
        "status": "success",
        "data": users_db
    })

@app.route('/api/users/<int:user_id>', methods=['GET'])
def get_user(user_id):
    user = next((u for u in users_db if u['id'] == user_id), None)
    if user:
        return jsonify(user)
    return jsonify({"error": "User not found"}), 404

if __name__ == '__main__':
    app.run(debug=True)

測試方式： 啟動後在瀏覽器訪問 http://127.0.0.1:5000/api/users，即可看到 JSON 格式的資料。

Demo 2 藍圖 Blueprint (模組化專案架構)

當專案變大時，把所有路由都寫在同一個 app.py 會導致檔案過大難以維護。Blueprint 允許我們將應用程式拆分成多個模組。

資料夾結構假設為：

  • app.py (主程式)
  • routes/auth.py (登入註冊模組)
routes/auth.py (認證模組)
from flask import Blueprint

# 建立 Blueprint 實例，設定 url_prefix 使該模組下所有路由自動加上 /auth 前綴
auth_bp = Blueprint('auth', __name__, url_prefix='/auth')

@auth_bp.route('/login')
def login():
    return "這裡是登入頁面 (路由為 /auth/login)"

@auth_bp.route('/register')
def register():
    return "這裡是註冊頁面 (路由為 /auth/register)"
app.py (主程式)
from flask import Flask
from routes.auth import auth_bp # 匯入寫好的 Blueprint

app = Flask(__name__)

# 將 Blueprint 註冊到主應用程式中
app.register_blueprint(auth_bp)

if __name__ == '__main__':
    app.run(debug=True)

Demo 3 資料庫整合 (Flask-SQLAlchemy)

使用 ORM (Object-Relational Mapping) 技術，我們可以用 Python 物件導向的方式操作資料庫，而不用手寫複雜的 SQL 語法。這裡以 SQLite 為例。

app_db.py
from flask import Flask, request, jsonify
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
# 設定資料庫連線位址 (使用本地端的 SQLite 檔案 data.db)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///data.db'
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False

db = SQLAlchemy(app)

# 定義資料表模型 (Model)
class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True, nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False)

# 建立資料庫與資料表 (必須在 app context 內執行)
with app.app_context():
    db.create_all()

@app.route('/add_user', methods=['POST'])
def add_user():
    # 建立新使用者物件
    new_user = User(username='JohnDoe', email='john@example.com')
    # 加入並儲存到資料庫
    db.session.add(new_user)
    db.session.commit()
    return "使用者新增成功！"

Demo 4 檔案上傳處理 (File Upload)

處理使用者上傳的圖片或文件。請注意 HTML 表單必須加上 enctype="multipart/form-data"。

app_upload.py
from flask import Flask, request, render_template_string
import os
from werkzeug.utils import secure_filename

app = Flask(__name__)
# 設定上傳資料夾徑路
UPLOAD_FOLDER = './uploads'
os.makedirs(UPLOAD_FOLDER, exist_ok=True)
app.config['UPLOAD_FOLDER'] = UPLOAD_FOLDER

@app.route('/upload', methods=['GET', 'POST'])
def upload_file():
    if request.method == 'POST':
        # 從表單中獲取名為 'file' 的檔案
        file = request.files.get('file')
        
        if file and file.filename != '':
            # secure_filename 可過濾危險字元，確保檔名安全
            filename = secure_filename(file.filename)
            filepath = os.path.join(app.config['UPLOAD_FOLDER'], filename)
            file.save(filepath) # 儲存檔案
            return f"檔案 {filename} 上傳成功！"
            
    return render_template_string('''
        <form method="POST" enctype="multipart/form-data">
            <input type="file" name="file">
            <input type="submit" value="上傳">
        </form>
    ''')

Demo 5 Session 狀態管理 (簡易登入機制)

HTTP 是無狀態的，為了記住使用者的狀態（例如是否已登入），我們使用 Session。Flask 會將 Session 資料加密後儲存在使用者的 Cookie 中。

app_session.py
from flask import Flask, session, redirect, url_for, request

app = Flask(__name__)
# 使用 Session 必須設定 secret_key 用來加密
app.secret_key = 'your_super_secret_key_here'

@app.route('/')
def index():
    # 檢查 session 中是否有 'username'
    if 'username' in session:
        return f"歡迎回來，{session['username']}！ <a href='/logout'>登出</a>"
    return "您尚未登入。 <a href='/login'>登入</a>"

@app.route('/login', methods=['GET', 'POST'])
def login():
    if request.method == 'POST':
        # 模擬帳密驗證成功，將使用者資訊存入 session (類似字典的操作)
        session['username'] = request.form.get('username')
        return redirect(url_for('index')) # 重新導向回首頁
        
    return '''
        <form method="POST">
            帳號: <input type="text" name="username">
            <input type="submit" value="登入">
        </form>
    '''

@app.route('/logout')
def logout():
    # 從 session 中移除 'username'
    session.pop('username', None)
    return redirect(url_for('index'))

if __name__ == '__main__':
    app.run(debug=True)
