Demo 1 RESTful API 開發 (JSON 回傳與解析)

現代網頁開發常採用前後端分離，後端只需提供 JSON 格式的 API 讓前端 (如 Vue, React, App) 呼叫。我們會用到 jsonify 與 request.get_json()。

app.py
from flask import Flask, jsonify, request

app = Flask(__name__)

# 模擬資料庫
users = [{"id": 1, "name": "Alice"}, {"id": 2, "name": "Bob"}]

# GET: 取得所有使用者
@app.route('/api/users', methods=['GET'])
def get_users():
    return jsonify({"status": "success", "data": users})

# POST: 新增使用者 (接收前端傳來的 JSON 資料)
@app.route('/api/users', methods=['POST'])
def create_user():
    data = request.get_json() # 解析 JSON 資料
    if not data or 'name' not in data:
        return jsonify({"error": "Invalid data"}), 400
        
    new_user = {"id": len(users) + 1, "name": data['name']}
    users.append(new_user)
    return jsonify(new_user), 201 # 201 Created

Demo 2 Blueprint (藍圖) 模組化專案架構

當路由多達數十個時，寫在同一個檔案會難以維護。Blueprint 允許我們將路由拆分到不同的 Python 檔案中。

routes/admin.py (後台模組)
from flask import Blueprint

# 建立藍圖，設定 url_prefix 使此藍圖下的路由都帶有 /admin 前綴
admin_bp = Blueprint('admin', __name__, url_prefix='/admin')

@admin_bp.route('/dashboard')
def dashboard():
    return "這裡是後台控制面板"
app.py (主程式)
from flask import Flask
from routes.admin import admin_bp # 匯入藍圖

app = Flask(__name__)

# 將藍圖註冊到主程式
app.register_blueprint(admin_bp)

if __name__ == '__main__':
    app.run()

Demo 3 資料庫整合 (Flask-SQLAlchemy)

使用 ORM 技術，我們能用 Python 物件導向的方式操作資料庫，免去手寫 SQL 語法的麻煩。這裡以 SQLite 示範。

app.py
from flask import Flask
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)
# 設定資料庫位置 (SQLite)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///site.db'
db = SQLAlchemy(app)

# 定義資料表模型 (Model)
class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(20), unique=True, nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False)

# 建立資料表 (需要在 app 範圍內執行)
with app.app_context():
    db.create_all()

@app.route('/add')
def add_user():
    # 透過 ORM 新增資料
    user1 = User(username='Tony', email='tony@example.com')
    db.session.add(user1)
    db.session.commit()
    return "使用者已寫入資料庫！"

Demo 4 檔案上傳處理 (File Upload)

處理使用者上傳的圖片或文件，我們需要確保檔名安全，並指定儲存目錄。

app.py
import os
from flask import Flask, request, redirect, url_for
from werkzeug.utils import secure_filename

app = Flask(__name__)
UPLOAD_FOLDER = './uploads'
os.makedirs(UPLOAD_FOLDER, exist_ok=True)
app.config['UPLOAD_FOLDER'] = UPLOAD_FOLDER

@app.route('/upload', methods=['POST'])
def upload_file():
    if 'file' not in request.files:
        return '沒有選擇檔案'
        
    file = request.files['file']
    if file.filename == '':
        return '檔案名稱不可為空'
        
    if file:
        # 過濾危險字元確保檔名安全
        filename = secure_filename(file.filename)
        save_path = os.path.join(app.config['UPLOAD_FOLDER'], filename)
        file.save(save_path) # 儲存檔案到硬碟
        return f'檔案 {filename} 上傳成功！'

注意： HTML 表單必須加上 enctype="multipart/form-data" 才能成功上傳檔案。

Demo 5 Session 狀態與權限管理

HTTP 是無狀態的。為了記住「誰登入了網站」，我們把登入資訊存入 session 中。Flask 會自動將其加密存在使用者的 Cookie 裡。

app.py
from flask import Flask, session, request

app = Flask(__name__)
# 使用 Session 必須設定一把 Secret Key 來加密資料
app.secret_key = 'super_secret_key_12345'

@app.route('/login', methods=['POST'])
def login():
    username = request.form.get('username')
    # 驗證成功後，將帳號存入 session (類似操作字典)
    session['user'] = username
    return '登入成功！'

@app.route('/profile')
def profile():
    # 檢查 session 中是否有 'user'，用來判斷是否已登入
    if 'user' in session:
        return f"歡迎回來，{session['user']}"
    return "請先登入！", 401

@app.route('/logout')
def logout():
    # 從 session 中移除該使用者
    session.pop('user', None)
    return '已登出'

Demo 6 錯誤處理與自訂 404 頁面

在進階專案中，我們不應該讓使用者看到預設的白底黑字錯誤畫面。透過裝飾器 @app.errorhandler，我們可以攔截特定錯誤並回傳自訂的頁面。

app.py
from flask import Flask, render_template_string

app = Flask(__name__)

# 捕捉 404 Not Found 錯誤
@app.errorhandler(404)
def page_not_found(error):
    # 你可以回傳一個精美的 error_404.html 模板
    return render_template_string("<h1>Oops! 找不到這個網頁 (404)</h1>"), 404

# 捕捉 500 Internal Server Error 錯誤 (伺服器內部錯誤)
@app.errorhandler(500)
def internal_server_error(error):
    return "伺服器發生異常，工程師正在搶修中！(500)", 500

@app.route('/crash')
def crash():
    # 故意觸發一個例外，測試 500 錯誤畫面
    return 1 / 0
