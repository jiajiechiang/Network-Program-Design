一、教學規劃與大綱

Flask 是一個微型 Web 框架 (Micro-framework)，非常適合初學者入門，同時也具備擴展成大型專案的潛力。教學應遵循「先見樹，後見林」的原則：

  • 基礎階段： 讓學生快速看到畫面，建立成就感。著重於 Routing (路由) 和回傳字串。
  • 中階階段： 引入前端概念，教導 Jinja2 模板引擎 與 GET/POST 請求，達成前後端互動。
  • 進階階段： 進入業界實務，教授 API 開發 (JSON) 與專案架構拆分 Blueprint。

二、基礎篇：起步與路由

首先，確保已經安裝 Flask：pip install Flask

1. Hello World (最小應用程式)

from flask import Flask

# 初始化 Flask 應用程式
app = Flask(__name__)

# 設定路由 (Route)
@app.route('/')
def hello_world():
    return 'Hello, Flask World!'

if __name__ == '__main__':
    # 啟動伺服器，開啟除錯模式 (debug=True)
    app.run(debug=True)

2. 動態路由 (Dynamic Routing)

透過 URL 傳遞參數給後端。

@app.route('/user/<username>')
def show_user_profile(username):
    return f'User: {username}'

@app.route('/post/<int:post_id>')
def show_post(post_id):
    return f'Post ID: {post_id}'

三、中階篇：模板與表單處理

1. 渲染 HTML 模板 (Jinja2)

建立一個名為 templates 的資料夾，並在裡面建立 index.html。Flask 會自動去該資料夾尋找。

from flask import render_template

@app.route('/hello/<name>')
def hello_name(name):
    # 將變數 name 傳遞給 index.html 模板
    return render_template('index.html', person=name)

2. 處理 GET 與 POST 請求

網頁表單送出時最常用到 POST 方法。

from flask import request

@app.route('/login', methods=['GET', 'POST'])
def login():
    if request.method == 'POST':
        username = request.form.get('username')
        password = request.form.get('password')
        return f'嘗試登入的帳號：{username}'
    else:
        # GET 請求：顯示登入表單畫面
        return '''
            <form method="post">
                帳號: <input type="text" name="username"><br>
                密碼: <input type="password" name="password"><br>
                <input type="submit" value="登入">
            </form>
        '''

四、進階篇：RESTful API 與藍圖 (Blueprint)

1. 回傳 JSON 資料 (開發 API)

現代 Web 開發常將前後端分離，後端只需提供 JSON 格式的 API。

from flask import jsonify

@app.route('/api/users')
def get_users():
    users = [
        {'id': 1, 'name': 'Alice', 'role': 'Admin'},
        {'id': 2, 'name': 'Bob', 'role': 'User'}
    ]
    return jsonify(users)

2. Blueprint (模組化大型專案)

當專案變大時，把所有路由寫在同一個檔案會難以維護。Blueprint 允許我們將路由拆分到多個檔案中。

auth.py (認證模組):

from flask import Blueprint

auth_bp = Blueprint('auth', __name__, url_prefix='/auth')

@auth_bp.route('/login')
def login():
    return "這是登入頁面"

@auth_bp.route('/logout')
def logout():
    return "這是登出頁面"

app.py (主程式):

from flask import Flask
from auth import auth_bp

app = Flask(__name__)

# 註冊 Blueprint
app.register_blueprint(auth_bp)

if __name__ == '__main__':
    app.run(debug=True)
