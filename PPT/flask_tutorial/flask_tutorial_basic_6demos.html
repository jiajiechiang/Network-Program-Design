Python Flask 基礎教學指南

從零開始：環境建置與 6 大基礎觀念實戰範例

環境建置提醒： 開始之前，請確保您已安裝 Python 並建立虛擬環境。
在終端機輸入：pip install Flask 來安裝 Flask 套件。

Demo 1 第一個 Flask 應用 (Hello World)

這是所有 Flask 專案的起點。我們會初始化一個 Flask 應用，設定一個路由 (Route)，並啟動伺服器。

app.py
from flask import Flask

# 1. 初始化 Flask 應用程式
# __name__ 代表當前模組名稱，Flask 會用它來尋找資源
app = Flask(__name__)

# 2. 設定路由 (Route)
# 當使用者訪問網站根目錄 '/' 時，會執行以下函式
@app.route('/')
def hello_world():
    return 'Hello, Flask World!'

# 3. 啟動伺服器
if __name__ == '__main__':
    # 開啟 debug 模式，存檔時會自動重新載入伺服器
    app.run(debug=True)

測試： 在終端機執行 python app.py，接著打開瀏覽器前往 http://127.0.0.1:5000/。

Demo 2 多重路由 (Multiple Routes)

一個網站通常會有多個頁面（例如首頁、關於我們、聯絡我們）。我們可以設定多個不同的 `@app.route()` 來處理。

app.py
from flask import Flask

app = Flask(__name__)

@app.route('/')
def home():
    return '這是網站首頁'

@app.route('/about')
def about():
    return '這是關於我們的頁面'

@app.route('/contact')
def contact():
    return '請撥打客服專線：0800-000-000'

if __name__ == '__main__':
    app.run(debug=True)

Demo 3 動態路由 (URL 參數捕捉)

如果我們有 100 個使用者，不可能寫 100 個路由。動態路由允許我們將網址的一部分當作變數傳入函式中。

app.py
from flask import Flask

app = Flask(__name__)

# 捕捉字串 (預設)
@app.route('/user/<username>')
def show_user_profile(username):
    return f'使用者名稱：{username}'

# 捕捉整數 (限制只能輸入數字)
@app.route('/post/<int:post_id>')
def show_post(post_id):
    # post_id 的型態會是 int
    return f'你正在觀看第 {post_id} 篇文章'

if __name__ == '__main__':
    app.run(debug=True)

測試： 訪問 http://127.0.0.1:5000/post/42，如果輸入 /post/abc 會得到 404 錯誤，因為 abc 不是整數。

Demo 4 基礎 HTML 標籤回傳

在學習模板引擎（如 Jinja2）之前，我們可以透過直接回傳 HTML 字串來改變網頁外觀。

app.py
from flask import Flask

app = Flask(__name__)

@app.route('/')
def html_demo():
    # 直接回傳帶有 HTML 標籤的字串，瀏覽器會自動解析它
    html_content = '''
        <h1 style="color: blue;">歡迎來到我的 Flask 網站</h1>
        <hr>
        <p>這是一段簡單的文字介紹。</p>
        <ul>
            <li>項目一</li>
            <li>項目二</li>
        </ul>
    '''
    return html_content

if __name__ == '__main__':
    app.run(debug=True)

Demo 5 基礎 HTTP 請求方法 (GET / POST)

預設情況下，瀏覽器訪問網頁都是使用 GET 請求。若要處理表單送出的資料，我們需要允許路由接收 POST 請求。

app.py
from flask import Flask, request

app = Flask(__name__)

# 在 methods 參數中宣告此路由允許 GET 與 POST 請求
@app.route('/login', methods=['GET', 'POST'])
def login():
    if request.method == 'POST':
        return '這是一個 POST 請求！(通常發生在表單送出時)'
    else:
        return '這是一個 GET 請求！(通常發生在直接輸入網址時)'

if __name__ == '__main__':
    app.run(debug=True)

Demo 6 網址重新導向 (Redirect & URL For)

當使用者存取某個舊網址，或是登入成功後，我們通常會將他們自動「重新導向」(Redirect) 到首頁或其他頁面。

app.py
from flask import Flask, redirect, url_for

app = Flask(__name__)

@app.route('/')
def home():
    return '這裡是網站首頁！'

# 假設這是一個舊的路由
@app.route('/old-home')
def old_home():
    # url_for('home') 會自動尋找名為 'home' 的函式，並產生對應的網址 '/'
    # redirect() 則會將瀏覽器重新導向到該網址
    return redirect(url_for('home'))

# 動態路由的重導向寫法
@app.route('/guest')
def guest():
    # 重導向至 /user/Guest (對應 Demo 3 的 show_user_profile)
    return redirect(url_for('show_user_profile', username='Guest'))

if __name__ == '__main__':
    app.run(debug=True)
