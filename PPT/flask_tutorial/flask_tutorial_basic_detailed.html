基礎範例二：動態路由 (Dynamic Routing)

很多時候，我們希望網址是可以變動的，例如 /user/alice 和 /user/bob，而不需要為每個使用者寫一個獨立的路由。這就是動態路由。

修改 app.py 加入新的路由：

from flask import Flask

app = Flask(__name__)

@app.route('/')
def home():
    return '歡迎來到首頁'

# 1. 捕捉字串參數
# <username> 會捕捉網址列上的字串，並作為參數傳遞給 show_user_profile 函式。
@app.route('/user/<username>')
def show_user_profile(username):
    return f'使用者頁面，帳號名稱為：{username}'

# 2. 捕捉特定型別的參數 (例如整數 int)
# <int:post_id> 指定這個部分必須是整數。
@app.route('/post/<int:post_id>')
def show_post(post_id):
    # 注意：這裡的 post_id 型別會是 int，而不是字串。
    return f'您正在觀看第 {post_id} 篇文章。'

if __name__ == '__main__':
    app.run(debug=True)

測試動態路由：

  • 瀏覽 http://localhost:5000/user/Tony，畫面會顯示「使用者頁面，帳號名稱為：Tony」
  • 瀏覽 http://localhost:5000/post/42，畫面會顯示「您正在觀看第 42 篇文章。」
  • 錯誤測試： 嘗試瀏覽 http://localhost:5000/post/abc，因為 abc 不是整數，Flask 會回傳 404 Not Found 錯誤。
