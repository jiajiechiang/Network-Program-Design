Demo 1 Netmiko 批次設定部署與指令發送

管理數十台路由器時，需要安全地批次發送設定命令。Netmiko 的 send_config_set 可以自動幫我們進入全域設定模式 (Config Mode) 並批次套用。

netmiko_batch_config.py
from netmiko import ConnectHandler

# 定義設備連線參數字典
cisco_router = {
    'device_type': 'cisco_ios',
    'host': '192.168.1.1',
    'username': 'admin',
    'password': 'secret_password',
    'secret': 'enable_password', # 若需進入 enable 模式
}

try:
    print("正在連線至設備...")
    with ConnectHandler(**cisco_router) as net_connect:
        # 準備要批次執行的設定指令列表
        config_commands = [
            'interface Loopback0',
            'ip address 10.255.255.1 255.255.255.255',
            'description Managed by Python Automation',
            'no shutdown'
        ]
        
        print("開始套用設定...")
        output = net_connect.send_config_set(config_commands)
        print(output)
        
        # 儲存設定
        save_output = net_connect.save_config()
        print("設定已儲存：", save_output)
        
except Exception as e:
    print(f"連線或設定失敗：{e}")

Demo 2 Netmiko 透過 SCP 進行設定備份

網管人員每日例行公事：將設備的 running-config 透過 SCP 或指令抓取並儲存到本地端歸檔。

netmiko_backup.py
from netmiko import ConnectHandler
import time

device = {
    'device_type': 'cisco_ios',
    'host': '192.168.1.1',
    'username': 'admin',
    'password': 'secret_password'
}

with ConnectHandler(**device) as net_connect:
    # 1. 抓取 running-config 文字輸出
    config_content = net_connect.send_command('show running-config')
    
    # 2. 依照當前日期產生動態檔名
    filename = f"backup_{device['host']}_{time.strftime('%Y%m%d_%H%M%S')}.cfg"
    
    # 3. 寫入本地檔案
    with open(filename, 'w', encoding='utf-8') as f:
        f.write(config_content)
        
    print(f"備份成功！檔案已儲存為：{filename}")

Demo 3 NAPALM 跨廠牌標準化資訊擷取 (Getters)

寫自動化腳本最痛苦的是 Cisco 和 Juniper 的指令長得不一樣。NAPALM 提供統一的 API，呼叫相同的函式就能回傳結構化的 Python 字典 (Dictionary)。

napalm_getters.py
from napalm import get_network_driver

# 指定驅動程式類型 (cisco_ios, junos, arista_eos 等)
driver = get_network_driver('ios')

# 建立連線
device = driver(
    hostname='192.168.1.1',
    username='admin',
    password='secret_password'
)

device.open()
print("已成功透過 NAPALM 連線設備")

# 1. 取得設備基本事實 (型號、序號、版本等)
facts = device.get_facts()
print("設備型號：", facts['model'])
print("作業系統版本：", facts['os_version'])

# 2. 取得介面 IP 位址資訊
ip_interfaces = device.get_interfaces_ip()
print("介面 IP 狀態：", ip_interfaces)

# 3. 取得 ARP 表
arp_table = device.get_arp_table()
print(f"目前 ARP 紀錄筆數：{len(arp_table)}")

device.close()

Demo 4 NAPALM 設定比對 (Diff) 與 Rollback 回滾機制

上線新設定最怕手殘打錯導致斷線。NAPALM 支援「先比較差異 (Diff)，確認無誤再提交 (Commit)，出事一鍵還原 (Rollback)」的安全發布流程。

napalm_diff_rollback.py
from napalm import get_network_driver

driver = get_network_driver('ios')
device = driver(hostname='192.168.1.1', username='admin', password='secret')
device.open()

# 1. 載入想要替換或新增的設定檔 (可指定檔案或字串)
device.load_replace_candidate(filename='new_router_config.cfg')
# 2. 比對當前設定與候選設定的差異 (Diff)
diffs = device.compare_config()
print("=== 設定差異比對 (Diff) ===")
print(diffs if diffs else "沒有任何差異")

if diffs:
    user_input = input("確認要套用以上變更嗎？(y/n): ")
    if user_input.lower() == 'y':
        device.commit_config()
        print("設定已成功 Commit！")
        
        # 假設發現網路不通，可以立刻執行 Rollback 還原到異動前的狀態！
        # device.rollback()
    else:
        device.discard_config()
        print("已放棄變更，清除候選設定。")

device.close()

Demo 5 Nornir 框架：使用 Inventory 與多執行緒平行自動化

當設備量達到上百台時，循序跑腳本會花費數小時。Nornir 是基於純 Python 的自動化框架，內建多執行緒排程，能同時對多台設備派發任務。

config.yaml (Nornir 設定檔)
runner:
  plugin: threaded
  options:
    num_workers: 20  # 同時開啟 20 個執行緒併發處理

inventory:
  plugin: SimpleInventory
  options:
    host_file: "inventory/hosts.yaml"
    group_file: "inventory/groups.yaml"
nornir_threaded_task.py
from nornir import InitNornir
from nornir_netmiko.tasks import netmiko_send_command
from nornir_utils.plugins.functions import print_result

# 初始化 Nornir，讀取 config.yaml
nr = InitNornir(config_file="config.yaml")

# 定義要在所有設備上執行的任務
def check_cpu_memory(task):
    # 使用 netmiko 發送指令
    result = task.run(
        task=netmiko_send_command,
        command_string="show processes cpu sorted | exclude 0.00%"
    )
    # 將結果記錄或印出
    task.host["cpu_output"] = result.result

# 透過 .run() 派發任務，Nornir 會自動使用多執行緒同時對 inventory 中的所有設備發動請求！
results = nr.run(task=check_cpu_memory)

# 內建的美化輸出函式
print_result(results)

Demo 6 Nornir 結合 NAPALM：批次驗證網路健康狀態

結合 Nornir 的高速併發與 NAPALM 的標準化檢測能力，我們可以一秒鐘巡檢全網路由器的 BGP 鄰居狀態、介面 Up/Down 狀況，並產出健康報告。

nornir_napalm_audit.py
from nornir import InitNornir
from nornir_napalm.plugins.tasks import napalm_get
from nornir_utils.plugins.functions import print_result

nr = InitNornir(config_file="config.yaml")

def audit_network_health(task):
    # 使用 NAPALM 取得介面狀態與 BGP 鄰居狀態
    result = task.run(
        task=napalm_get,
        getters=["interfaces", "bgp_neighbors"]
    )
    
    facts = result.result
    task.host["interfaces_data"] = facts["interfaces"]
    task.host["bgp_data"] = facts["bgp_neighbors"]

# 執行稽核任務
results = nr.run(task=audit_network_health)
print_result(results)
