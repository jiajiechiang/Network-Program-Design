網路安全監控自動化環境準備：
網路安全不只需要防火牆，更需要定期對企業內部的路由器、交換器進行「資安合規檢查 (Compliance Audit)」與「異常連線監控」。

請在終端機安裝：pip install netmiko napalm requests

Demo 1 自動檢查設備是否強制啟用密碼加密 (Service Password-Encryption)

在 Cisco 設備中，若未開啟 `service password-encryption`，明文密碼會直接暴露在 `running-config` 之中。此範例教您自動巡檢全網設備是否有落實此項資安基本要求。

audit_password_encryption.py
from netmiko import ConnectHandler

device = {
    'device_type': 'cisco_ios',
    'host': '192.168.1.1',
    'username': 'admin',
    'password': 'secret'
}

with ConnectHandler(**device) as conn:
    output = conn.send_command('show running-config | include password-encryption')
    
    if 'service password-encryption' in output:
        print("✅ [安全] 此設備已啟用密碼加密保護。")
    else:
        print("⚠️ [資安警告] 此設備未啟用 service password-encryption！密碼可能以明文外洩。")

Demo 2 檢查高風險通訊埠：偵測 Telnet 是否意外開啟

Telnet 是明文傳輸協定，極易遭到中間人攻擊 (MitM)。資安規範要求所有設備必須全面關閉 Telnet，改用 SSH。此範例自動檢測 VTY 遠端線路設定。

audit_vty_telnet.py
from netmiko import ConnectHandler

device = {
    'device_type': 'cisco_ios',
    'host': '192.168.1.1',
    'username': 'admin',
    'password': 'secret'
}

with ConnectHandler(**device) as conn:
    # 檢查 VTY 線路允許的輸人生協定
    output = conn.send_command('show running-config | section line vty')
    
    if 'transport input ssh' in output and 'telnet' not in output:
        print("✅ [安全] VTY 遠端線路僅允許 SSH 登入。")
    else:
        print("🚨 [嚴重資安漏洞] VTY 線路允許 Telnet 登入，請立即修正！")

Demo 3 監控異常存取：自動備份與檢查 AAA 認證設定

企業級網路安全要求透過 AAA (TACACS+ / RADIUS) 伺服器集中管理帳號，而非使用本機帳號。此範例自動稽核設備是否正確套用 AAA 登入驗證。

audit_aaa_settings.py
from netmiko import ConnectHandler

device = {
    'device_type': 'cisco_ios',
    'host': '192.168.1.1',
    'username': 'admin',
    'password': 'secret'
}

with ConnectHandler(**device) as conn:
    output = conn.send_command('show running-config | include aaa new-model')
    
    if 'aaa new-model' in output:
        print("✅ [合規] 設備已啟用 AAA 模型。")
    else:
        print("⚠️ [注意] 設備未啟用 AAA，目前依賴本機帳號驗證。")

Demo 4 網路拓樸與介面安全：自動關閉未使用的介面 (Port Security 概念)

資安防護中，長期未使用的連接埠若未關閉 (`shutdown`)，可能遭內部有心人士私接小路由器或攻擊。此範例自動尋找處於 `down` 狀態的介面。

audit_unused_ports.py
from netmiko import ConnectHandler

device = {
    'device_type': 'cisco_ios',
    'host': '192.168.1.1',
    'username': 'admin',
    'password': 'secret'
}

with ConnectHandler(**device) as conn:
    # 使用 TextFSM 結構化解析介面狀態
    interfaces = conn.send_command('show ip interface brief', use_textfsm=True)
    
    print("=== 閒置介面安全稽核清單 ===")
    for intf in interfaces:
        if 'administratively down' in intf['status'].lower():
            print(f"  [安全] 介面 {intf['interface']} 已手動關閉。")
        elif 'down' in intf['status'].lower():
            print(f"  💡 [建議] 介面 {intf['interface']} 目前閒置 (down)，建議進行 shutdown 封鎖。")

Demo 5 即時安全告警：結合 Webhook 發送異常通知至 Chat (Slack / Teams)

當自動化腳本巡檢到資安漏洞（如 Telnet 未關閉）時，不能只印在螢幕上，必須主動透過 HTTP Requests 發送 Webhook 告警至即時通訊軟體。

security_webhook_alert.py
import requests

def send_security_alert(message):
    # 企業內部 Chat / Teams / Slack Webhook 網址
    webhook_url = "https://oapi.dingtalk.com/robot/send?access_token=YOUR_TOKEN_HERE"
    
    payload = {
        "msgtype": "text",
        "text": {
            "content": f"🚨 【網管資安告警】\n{message}"
        }
    }
    
    response = requests.post(webhook_url, json=payload)
    if response.status_code == 200:
        print("安全告警訊息已成功推播至即時通訊群組！")
    else:
        print("告警發送失敗。")

# 模擬觸發告警
send_security_alert("偵測到核心交換器 192.168.1.1 關閉了 Port Security 檢查！")
