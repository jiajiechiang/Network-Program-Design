Python 網路自動化基礎教學

從手動 CLI 邁向自動化管理：Paramiko 底層 SSH 與 Netmiko 高階套件 6 大入門實戰

基礎網管自動化環境準備：
傳統網管需要工程師一台一台登入路由器敲指令。Python 自動化能透過 SSH 通訊協定瞬間完成設備巡檢與指令下發。

基礎篇我們將學習底層的 Paramiko 以及專為網路設備設計的高階套件 Netmiko。
請在終端機安裝：pip install paramiko netmiko

Demo 1 Paramiko 底層 SSH：單一設備指令發送

Paramiko 是 Python 最經典的純 SSHv2 協議函式庫。我們透過它建立安全的 SSH 通訊管道，並發送 `show version` 指令抓取系統資訊。

paramiko_ssh_basic.py
import paramiko
import time

HOST = '192.168.1.1'
PORT = 22
USER = 'admin'
PASS = 'secret_password'

# 1. 建立 SSHClient 實例
ssh = paramiko.SSHClient()

# 2. 自動接受未知主機的 SSH Key (避免首次連線卡住詢問 yes/no)
ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy())

try:
    print(f"正在連線至 {HOST}...")
    ssh.connect(hostname=HOST, port=PORT, username=USER, password=PASS, timeout=5)
    
    # 3. 開啟互動式 Shell 頻道
    shell = ssh.invoke_shell()
    time.sleep(1)
    
    # 4. 發送指令
    shell.send('show version\n')
    time.sleep(2)
    
    # 5. 接收並解碼輸出結果
    output = shell.recv(65535).decode('utf-8')
    print(output)
    
except Exception as e:
    print(f"連線失敗：{e}")
finally:
    ssh.close()

Demo 2 解決提示字元卡住：Netmiko 登場

用 Paramiko 處理網路設備時，常會遇到「命令分頁 (---More---)」或提示字元未回傳導致程式卡死的問題。Netmiko 是基於 Paramiko 封裝的高階套件，專門用來解決這些痛點。

netmiko_simple_connect.py
from netmiko import ConnectHandler

# 定義設備基本參數字典
cisco_switch = {
    'device_type': 'cisco_ios', # 指定設備廠牌型號，Netmiko 會自動處理互動特性
    'host': '192.168.1.2',
    'username': 'admin',
    'password': 'secret_password',
}

try:
    print("透過 Netmiko 建立連線...")
    # 使用 with 語法，離開時會自動關閉 SSH 連線
    with ConnectHandler(**cisco_switch) as net_connect:
        
        # 發送單一唯讀指令 (自動處理 More 分頁與等待提示字元)
        output = net_connect.send_command('show ip interface brief')
        
        print("=== 介面狀態結果 ===")
        print(output)
        
except Exception as e:
    print(f"Netmiko 連線錯誤：{e}")

Demo 3 批次巡檢：多台設備清單迴圈 (For Loop)

網管自動化的精髓在於規模化。我們可以使用 Python 的清單與迴圈，依序對多台不同 IP 的路由器發送相同的巡檢指令。

netmiko_multi_devices.py
from netmiko import ConnectHandler

# 定義多台設備清單
devices_list = [
    {
        'device_type': 'cisco_ios',
        'host': '192.168.1.10',
        'username': 'admin',
        'password': 'password123',
    },
    {
        'device_type': 'cisco_ios',
        'host': '192.168.1.11',
        'username': 'admin',
        'password': 'password123',
    }
]

for dev_params in devices_list:
    print(f"\n--- 正在巡檢設備: {dev_params['host']} ---")
    try:
        with ConnectHandler(**dev_params) as conn:
            uptime = conn.send_command('show version | include uptime')
            print(uptime.strip())
    except Exception as e:
        print(f"無法連線至 {dev_params['host']}：{e}")

Demo 4 輸出結果儲存：將巡檢結果寫入 TXT 檔案

自動化抓取資料後，通常需要存成記錄檔以便後續查閱或稽核。我們結合 Python 的檔案寫入操作來歸檔輸出。

netmiko_save_to_file.py
from netmiko import ConnectHandler

router = {
    'device_type': 'cisco_ios',
    'host': '192.168.1.1',
    'username': 'admin',
    'password': 'secret'
}

with ConnectHandler(**router) as conn:
    # 抓取 ARP 表
    arp_output = conn.send_command('show ip arp')
    
    filename = 'arp_report.txt'
    # 寫入檔案
    with open(filename, 'w', encoding='utf-8') as f:
        f.write("=== 網路自動化 ARP 巡檢報告 ===\n")
        f.write(arp_output)
        
    print(f"報表已成功儲存至 {filename}")

Demo 5 文字特徵解析：使用正則表達式 (Regex) 萃取資料

抓回來的指令輸出是一大串純文字。透過 Python 的 re 模組（正規表達式），我們可以精準抓取想要的數值 (例如介面狀態、CPU 使用率)。

netmiko_regex_parse.py
from netmiko import ConnectHandler
import re

router = {
    'device_type': 'cisco_ios',
    'host': '192.168.1.1',
    'username': 'admin',
    'password': 'secret'
}

with ConnectHandler(**router) as conn:
    output = conn.send_command('show ip interface brief')
    
    # 範例輸出某行：FastEthernet0/0   192.168.1.254   YES manual up      up
    # 我們使用正則表達式抓取介面名稱與 IP 狀態
    lines = output.splitlines()
    print(f"{'介面名稱':<20} | {'IP 位址':<15} | {'狀態':<10}")
    print("-" * 50)
    
    for line in lines:
        # 略過標題行
        if 'Interface' in line or '----' in line or not line.strip():
            continue
            
        parts = line.split()
        if len(parts) >= 5:
            intf, ip, status = parts[0], parts[1], parts[3]
            if ip != 'unassigned':
                print(f"{intf:<20} | {ip:<15} | {status:<10}")

Demo 6 異常處理與重試機制 (Try-Except)

網路環境瞬息萬變，設備可能重開機或發生網路逾時。基礎網管自動化必須具備強健的異常捕捉能力，避免腳本因為一台設備故障就全面崩潰。

netmiko_error_handling.py
from netmiko import ConnectHandler
from netmiko.exceptions import NetmikoTimeoutException, AuthenticationException

devices = ['192.168.1.1', '192.168.1.99'] # 99 為不存在的 IP

for ip in devices:
    config = {
        'device_type': 'cisco_ios',
        'host': ip,
        'username': 'admin',
        'password': 'wrong_or_right',
        'timeout': 3 # 設定 3 秒超時
    }
    
    try:
        print(f"嘗試連線至 {ip}...")
        with ConnectHandler(**config) as conn:
            res = conn.send_command('show clock')
            print(f"[{ip}] 系統時間：{res.strip()}")
            
    except NetmikoTimeoutException:
        print(f"❌ 錯誤：連線至 {ip} 逾時 (Timeout)，設備可能離線。")
    except AuthenticationException:
        print(f"🔒 錯誤：{ip} 帳號密碼驗證失敗 (Authentication Failed)。")
    except Exception as e:
        print(f"⚠️ 發生未預期的錯誤：{e}")
