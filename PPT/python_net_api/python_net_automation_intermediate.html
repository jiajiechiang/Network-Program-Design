Python 網路自動化中階教學

結構化網管：TextFSM 文字解析、Jinja2 模板生成、Netmiko 檔案傳輸與 Telnet 支援

中階自動化環境準備：
基礎篇我們學會了透過 Netmiko 抓取純文字。中階篇我們將學習如何將雜亂的純文字轉換成「結構化資料 (Structured Data)」，使用樣版動態產生設定檔，以及自動化檔案傳輸。

請在終端機安裝套件：pip install netmiko textfsm jinja2 pandas

Demo 1 結構化解析：使用 TextFSM 將 CLI 轉換為字典

傳統用正則表達式 (Regex) 切字串非常容易出錯。TextFSM 是一個由 Google 開發的強大工具，配合內建的樣版庫 (ntc-templates)，能自動把 `show ip interface brief` 變成乾淨的 Python 字典列表！

netmiko_textfsm_demo.py
from netmiko import ConnectHandler
import json

device = {
    'device_type': 'cisco_ios',
    'host': '192.168.1.1',
    'username': 'admin',
    'password': 'secret'
}

with ConnectHandler(**device) as net_connect:
    # Netmiko 只要加上 use_textfsm=True 參數，就會自動套用模板解析
    structured_data = net_connect.send_command(
        'show ip interface brief', 
        use_textfsm=True
    )
    
    print("=== 解析後的結構化資料 (List of Dictionaries) ===")
    print(json.dumps(structured_data, indent=4, ensure_ascii=False))

Demo 2 動態設定生成：使用 Jinja2 產生 VLAN 與介面設定

手動寫幾十行的 switch 設定很容易漏掉。我們可以使用 Jinja2 模板引擎，透過變數 (Variables) 動態迴圈產生整批標準化設定檔。

vlan_template.j2 (Jinja2 模板檔)
# 動態產生 VLAN 與介面設定
{% for vlan in vlans %}
vlan {{ vlan.id }}
 name {{ vlan.name }}
{% endfor %}

{% for intf in interfaces %}
interface {{ intf.name }}
 switchport mode access
 switchport access vlan {{ intf.vlan }}
 description Connected to {{ intf.desc }}
 no shutdown
{% endfor %}
generate_config.py (Python 生成器)
from jinja2 import Template

# 1. 準備要帶入模板的變數資料
template_data = {
    'vlans': [
        {'id': 10, 'name': 'Management'},
        {'id': 20, 'name': 'Employees'},
        {'id': 30, 'name': 'Guests'}
    ],
    'interfaces': [
        {'name': 'GigabitEthernet0/1', 'vlan': 20, 'desc': 'PC-Alice'},
        {'name': 'GigabitEthernet0/2', 'vlan': 20, 'desc': 'PC-Bob'}
    ]
}

# 2. 讀取模板並渲染
with open('vlan_template.j2', 'r', encoding='utf-8') as f:
    template_content = f.read()

t = Template(template_content)
rendered_config = t.render(template_data)

print("=== 成功動態生成的設備設定 ===")
print(rendered_config)

Demo 3 自動化批次派發：結合 Jinja2 與 Netmiko

將 Demo 2 產生的 Jinja2 動態設定，直接透過 Netmiko 的 send_config_set 批次推送到多台路由器上！

deploy_jinja_config.py
from netmiko import ConnectHandler
from jinja2 import Template

# 模擬動態生成設定指令
config_template = """
{% for vlan_id in vlans %}
vlan {{ vlan_id }}
{% endfor %}
"""
t = Template(config_template)
commands_list = t.render(vlans=[100, 200, 300]).strip().splitlines()

device = {
    'device_type': 'cisco_ios',
    'host': '192.168.1.1',
    'username': 'admin',
    'password': 'secret'
}

with ConnectHandler(**device) as conn:
    print("正在派發動態設定...")
    output = conn.send_config_set(commands_list)
    print(output)
    conn.save_config()

Demo 4 Netmiko 檔案傳輸：透過 SCP 上傳韌體或設定檔

除了敲指令，網管常常需要將新版韌體 (.bin) 或批次設定檔透過 SFTP/SCP 上傳到設備的 Flash 記憶體中。Netmiko 內建了便捷的檔案傳輸函式。

netmiko_scp_upload.py
from netmiko import ConnectHandler
from netmiko.scp_handler import FileTransfer

device = {
    'device_type': 'cisco_ios',
    'host': '192.168.1.1',
    'username': 'admin',
    'password': 'secret'
}

with ConnectHandler(**device) as net_connect:
    source_file = 'new_image.bin'
    destination_file = 'new_image.bin'
    
    # 初始化 FileTransfer 物件
    scp_handler = FileTransfer(
        net_connect, 
        source_file=source_file, 
        dest_file=destination_file, 
        direction='put' # 'put' 代表上傳到設備，'get' 代表從設備下載
    )
    
    if not scp_handler.check_file_exists():
        print("開始上傳檔案至設備 Flash...")
        scp_handler.transfer_file()
        print("檔案上傳完畢！")
    else:
        print("設備 Flash 中已經存在同名檔案，略過上傳。")

Demo 5 支援遺留設備：使用 Telnet 進行自動化連線

雖然多數現代設備使用 SSH，但部分老舊機房或測試環境仍強制使用 Telnet。Netmiko 只需要把 `device_type` 改成對應的 telnet 型號就能完美支援。

netmiko_telnet_connect.py
from netmiko import ConnectHandler

legacy_device = {
    'device_type': 'cisco_ios_telnet', # 指定 Telnet 驅動類型
    'host': '192.168.1.254',
    'username': 'admin',
    'password': 'legacy_secret',
    'port': 23 # Telnet 預設 Port
}

try:
    print("正在透過 Telnet 連線至老舊設備...")
    with ConnectHandler(**legacy_device) as conn:
        version = conn.send_command('show version')
        print(version[:300]) # 印出前 300 字元
except Exception as e:
    print(f"Telnet 連線失敗：{e}")

Demo 6 將巡檢結構化資料匯出為 Excel 報表 (Pandas)

結合 Demo 1 的 TextFSM 結構化解析與 Pandas 套件，我們能將全網路由器的介面 IP 與狀態一鍵匯出成整齊的 Excel 報表，供主管稽核！

export_network_excel.py
from netmiko import ConnectHandler
import pandas as pd

device = {
    'device_type': 'cisco_ios',
    'host': '192.168.1.1',
    'username': 'admin',
    'password': 'secret'
}

with ConnectHandler(**device) as conn:
    # 透過 TextFSM 取得結構化字典列表
    interfaces_data = conn.send_command('show ip interface brief', use_textfsm=True)
    
# 將 Python 列表轉換為 Pandas DataFrame
df = pd.DataFrame(interfaces_data)

# 匯出成 Excel 檔案
excel_filename = 'network_interfaces_report.xlsx'
df.to_excel(excel_filename, index=False, sheet_name='Interfaces')

print(f"結構化網路報表已成功匯出至：{excel_filename}")
