Python 網路 API 互動自動化基礎教學

從 CLI 走向現代 API 管理：透過 Requests 模組操作網路設備 REST API 與 IPAM 系統 6 大入門實戰

網路 API 自動化環境準備：
現代網路設備 (如 Cisco IOS-XE, Arista EOS, 雲端防火牆) 以及網管系統 (如 NetBox IPAM) 普遍支援 RESTful API。
相較於傳統透過 CLI 敲字串，使用 API 可以直接回傳結構化的 JSON 資料，精準又安全。

基礎篇我們將使用 Python 最核心的 HTTP 請求套件：requests。
請在終端機安裝：pip install requests urllib3

Demo 1 基礎 GET 請求：向網路設備 REST API 查詢系統狀態

網路 API 互動的第一步是發送 HTTP GET 請求。我們使用 requests.get() 取得網路設備或控制器的系統基礎資訊。

api_get_basic.py
import requests

# 略過安全性警告 (若設備使用自簽憑證 HTTPS)
import urllib3
urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

# 目標網路設備或控制器的 REST API 網址
api_url = "https://192.168.1.1/restconf/data/ietf-system:system-state"

# 發送 GET 請求 (帶入帳號密碼與略過憑證驗證)
response = requests.get(
    api_url, 
    auth=('admin', 'secret_password'), 
    verify=False,
    timeout=5
)

# 檢查 HTTP 狀態碼 (200 代表成功)
print("HTTP 狀態碼：", response.status_code)

if response.status_code == 200:
    # 將回傳的 JSON 轉為 Python 字典
    system_data = response.json()
    print("系統狀態資料：", system_data)
else:
    print(" API 請求失敗，錯誤代碼：", response.status_code)

Demo 2 設定 Headers 與 Accept 標頭 (指定 JSON 格式)

現代網路 API 通常支援多種資料格式 (如 JSON、XML)。我們需要在 HTTP 請求的 Headers 中明確宣告 Accept: application/json，確保設備回傳我們想要的 JSON 結構。

api_headers_demo.py
import requests
import urllib3
urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

api_url = "https://192.168.1.1/restconf/data/ietf-interfaces:interfaces"

# 定義標準的 API 請求標頭 (Headers)
headers = {
    "Accept": "application/yang-data+json",
    "Content-Type": "application/yang-data+json"
}

response = requests.get(
    api_url, 
    headers=headers, 
    auth=('admin', 'secret'), 
    verify=False
)

if response.status_code == 200:
    print("成功獲取介面設定資料！")
    print(response.json())
else:
    print("錯誤：", response.text)

Demo 3 HTTP POST 請求：透過 API 動態建立 VLAN 或設定

透過 API 不只能「看資料 (GET)」，更能「改資料 (POST/PUT)」。我們透過傳送 JSON 負載 (Payload)，讓路由器自動建立一個新的 VLAN。

api_post_config.py
import requests
import urllib3
urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

api_url = "https://192.168.1.1/restconf/data/Cisco-IOS-XE-native:native/vlan"

headers = {
    "Accept": "application/yang-data+json",
    "Content-Type": "application/yang-data+json"
}

# 準備要傳送的 JSON 設定內容 (Payload)
payload = {
    "Cisco-IOS-XE-native:vlan-list": [
        {
            "id": 100,
            "name": "API_Created_VLAN"
        }
    ]
}

# 發送 POST 請求
response = requests.post(
    api_url, 
    headers=headers, 
    json=payload, # requests 會自動將字典轉換為 JSON 字串
    auth=('admin', 'secret'), 
    verify=False
)

# RESTconf 建立成功通常回傳 201 Created 或 204 No Content
print("API 回應狀態碼：", response.status_code)
if response.status_code in [200, 201, 204]:
    print("✅ 透過 API 成功建立 VLAN 100！")
else:
    print("❌ 建立失敗：", response.text)

Demo 4 解析巢狀 JSON 資料：萃取特定介面與 IP 狀態

API 回傳的 JSON 通常結構很深（充滿巢狀字典與列表）。此範例教您如何使用 Python 精準剝開層層字典，抓出每個網路介面的名稱與 IP。

api_parse_json.py
import requests
import urllib3
urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

# 模擬 API 回傳的介面巢狀 JSON 資料結構
mock_api_response = {
    "ietf-interfaces:interfaces": {
        "interface": [
            {"name": "GigabitEthernet1", "enabled": True, "ipv4": {"ip": "192.168.1.1"}},
            {"name": "GigabitEthernet2", "enabled": False, "ipv4": {"ip": "10.0.0.1"}}
        ]
    }
}

interfaces = mock_api_response.get("ietf-interfaces:interfaces", {}).get("interface", [])

print(f"{'介面名稱':<20} | {'啟用狀態':<10} | {'IP 位址':<15}")
print("-" * 50)

for intf in interfaces:
    name = intf.get("name")
    enabled = "UP" if intf.get("enabled") else "DOWN"
    ip = intf.get("ipv4", {}).get("ip", "N/A")
    
    print(f"{name:<20} | {enabled:<10} | {ip:<15}")

Demo 5 完善的錯誤處理與 HTTP 狀態碼檢測

呼叫 API 時可能遇到伺服器逾時、帳密錯誤 (401) 或找不到資源 (404)。我們必須使用 try-except 與 response.raise_for_status() 來確保程式穩定。

api_error_handling.py
import requests
import urllib3
urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

api_url = "https://192.168.1.1/restconf/data/non-existent-path"

try:
    print("正在發送 API 請求...")
    response = requests.get(
        api_url, 
        auth=('admin', 'wrong_password'), 
        verify=False, 
        timeout=3
    )
    
    # 若 HTTP 狀態碼為 4xx 或 5xx，會自動引發 HTTPError 例外
    response.raise_for_status()
    
    print("成功：", response.json())

except requests.exceptions.HTTPError as err:
    print(f"🚨 HTTP 錯誤發生：{err} (狀態碼: {err.response.status_code})")
    if err.response.status_code == 401:
        print("🔒 提示：帳號或密碼驗證失敗。")
    elif err.response.status_code == 404:
        print("🔍 提示：找不到指定的 API 資源路徑。")
except requests.exceptions.Timeout:
    print("⏱️ 錯誤：API 連線逾時，設備可能離線或網路不通。")
except Exception as e:
    print(f"⚠️ 未預期的錯誤：{e}")
