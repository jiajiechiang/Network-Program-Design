中階安全自動化環境準備：
在基礎篇中我們學會了檢查密碼加密與 Telnet。中階篇我們將進一步探討更深度的資安議題：
1. 存取控制列表 (ACL) 稽核：自動檢查防火牆或路由器是否有過時或高風險的 `permit any any` 漏洞規則。
2. 流量異常偵測：監控介面封包錯誤率與丟包率 (Drops/Errors)，防範網路攻擊或硬體故障。

請在終端機安裝套件：pip install netmiko napalm pandas requests

Demo 1 存取控制列表 (ACL) 弱點掃描：偵測高風險 Any-Any 規則

在 ACL 中若設定了過度寬鬆的 permit ip any any，形同門戶大開。此範例自動檢查設備中的 ACL，尋找包含高風險的 `any any` 關鍵字並提出警告。

audit_acl_vulnerability.py
from netmiko import ConnectHandler

device = {
    'device_type': 'cisco_ios',
    'host': '192.168.1.1',
    'username': 'admin',
    'password': 'secret'
}

with ConnectHandler(**device) as conn:
    # 抓取設備上所有的存取控制列表 (ACL) 設定
    acl_output = conn.send_command('show access-lists')
    
    lines = acl_output.splitlines()
    risk_found = False
    
    print("=== 開始進行 ACL 弱點掃描 ===")
    for line in lines:
        # 檢查是否含有允許任何來源到任何目的地的寬鬆規則
        if 'permit ip any any' in line.lower() or 'permit any any' in line.lower():
            risk_found = True
            print(f"🚨 [高風險 ACL 漏洞] 發現寬鬆規則：{line.strip()}")
            
    if not risk_found:
        print("✅ 未發現明顯的 any any 高風險存取規則。")

Demo 2 介面錯誤率監控：防範 DDoS 或實體線路干擾

網路遭受攻擊或線路受損時，介面通常會出現大量的 CRC errors、`giants` 或 `input errors`。此範例定期自動抓取介面錯誤計數器，及早發現異常。

monitor_interface_errors.py
from netmiko import ConnectHandler

device = {
    'device_type': 'cisco_ios',
    'host': '192.168.1.1',
    'username': 'admin',
    'password': 'secret'
}

with ConnectHandler(**device) as conn:
    output = conn.send_command('show interfaces')
    
    # 簡單切段分析各介面的 Input/Output Errors 與 CRC
    interfaces = output.split('Ethernet')
    print("=== 介面錯誤率安全監控 ===")
    
    for part in interfaces[1:]:
        lines = part.splitlines()
        intf_name = 'Ethernet' + lines[0].split()[0]
        
        for line in lines:
            if 'crc' in line.lower():
                parts = line.strip().split(',')
                crc_part = [p for p in parts if 'crc' in p.lower()]
                if crc_part:
                    print(f"介面 {intf_name:<15} 錯誤數據: {crc_part[0].strip()}")

Demo 3 SSH 金鑰憑證審核：強制使用 RSA / Ed25519 強化遠端加密

過時的 SSH 版本 (如 SSHv1) 或過短的金鑰容易遭到破解。此範例透過自動化檢查設備的 SSH 憑證版本與強積體設定。

audit_ssh_version.py
from netmiko import ConnectHandler

device = {
    'device_type': 'cisco_ios',
    'host': '192.168.1.1',
    'username': 'admin',
    'password': 'secret'
}

with ConnectHandler(**device) as conn:
    output = conn.send_command('show ip ssh')
    
    if 'ssh enabled' not in output.lower():
        print("🚨 [警告] 設備未啟用 SSH！")
    else:
        print("✅ SSH 服務已啟用。")
        
    # 檢查是否支援 SSHv2
    if 'v2.0' in output:
        print("✅ [安全] 系統目前強制運行於 SSH v2 版本。")
    else:
        print("⚠️ [資安隱患] 系統可能允許不安全的 SSH v1 協定。")

Demo 4 自動化弱點修補：發現未加密密碼時自動套用修正指令

偵測到資安漏洞不夠，中階自動化教您如何「自己動手修」。當腳本發現未啟用密碼加密時，直接透過 Netmiko 自動把設定補上！

auto_remediate_security.py
from netmiko import ConnectHandler

device = {
    'device_type': 'cisco_ios',
    'host': '192.168.1.1',
    'username': 'admin',
    'password': 'secret'
}

with ConnectHandler(**device) as conn:
    output = conn.send_command('show running-config | include password-encryption')
    
    if 'service password-encryption' not in output:
        print("⚠️ 發現未加密密碼漏洞，正在自動執行資安修補...")
        
        remediate_commands = [
            'service password-encryption',
            'line vty 0 4',
            'transport input ssh' # 同時順便把 telnet 關掉
        ]
        
        fix_output = conn.send_config_set(remediate_commands)
        conn.save_config()
        print("✅ 資安修補指令已成功自動套用並存檔！")
        print(fix_output)
    else:
        print("✅ 檢查完畢，設備安全合規，無需修補。")

Demo 5 NAPALM 合規比對：以黃金設定 (Golden Config) 自動稽核

企業通常有標準的「黃金設定檔 (Golden Config)」。使用 NAPALM 的 compare_config() 功能，可以自動比對當前設備設定與標準設定的差距，揪出私自更改的違規設定。

napalm_golden_audit.py
from napalm import get_network_driver

driver = get_network_driver('ios')
device = driver(hostname='192.168.1.1', username='admin', password='secret')
device.open()

# 載入企業標準的黃金設定檔作為候選
device.load_replace_candidate(filename='golden_standard_config.cfg')

# 產生差異報告 (Diff)
diffs = device.compare_config()

if diffs:
    print("🚨 [合規警報] 設備設定與企業黃金標準不符，存在未授權的變更：")
    print(diffs)
    # 為了安全，自動放棄套用，僅印出違規報表
    device.discard_config()
else:
    print("✅ [合規] 設備設定完全符合企業黃金標準！")

device.close()

Demo 6 資安事件自動隔離：透過 API 封鎖惡意介面

當 SOC 資安中心偵測到某個連接埠 (例如 Port FastEthernet0/5) 正在發動 ARP 攻擊或遭受植入時，可以透過 Python 自動下達 `shutdown` 指令，第一時間隔離受害或被駭介面！

auto_quarantine_port.py
from netmiko import ConnectHandler
import requests

def quarantine_interface(target_ip, target_intf):
    device = {
        'device_type': 'cisco_ios',
        'host': target_ip,
        'username': 'admin',
        'password': 'secret'
    }
    
    try:
        with ConnectHandler(**device) as conn:
            print(f"⚠️ 正在對設備 {target_ip} 的 {target_intf} 執行資安強制隔離...")
            
            quarantine_cmds = [
                f'interface {target_intf}',
                'shutdown',
                'description QUARANTINED_BY_SECURITY_AUTOMATION'
            ]
            
            conn.send_config_set(quarantine_cmds)
            conn.save_config()
            print(f"✅ 介面 {target_intf} 已成功強制關閉 (Shutdown)！")
            
    except Exception as e:
        print(f"隔離失敗：{e}")

# 執行隔離動作
quarantine_interface('192.168.1.1', 'FastEthernet0/5')
