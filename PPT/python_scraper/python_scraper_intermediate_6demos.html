Demo 1 處理多頁面：自動翻頁抓取

資料通常會分散在多個頁面中。我們可以使用 for 迴圈與字串格式化 (f-string) 來動態產生網址並連續抓取。

demo1_pagination.py
import requests
from bs4 import BeautifulSoup
import time

# 假設目標網站的網址結構是 page=1, page=2...
base_url = "https://example.com/articles?page="

# 抓取第 1 頁到第 3 頁
for page in range(1, 4):
    url = f"{base_url}{page}"
    print(f"正在抓取：{url}")
    
    response = requests.get(url)
    soup = BeautifulSoup(response.text, "html.parser")
    
    # 假設每篇文章的標題都在 <h2 class="title"> 中
    titles = soup.find_all("h2", class_="title")
    for title in titles:
        print("-", title.text)
        
    # 禮貌性延遲，避免短時間發送過多請求被鎖 IP
    time.sleep(2)

Demo 2 抓取動態資料：直接呼叫 Ajax API (JSON)

很多現代網頁（如電商網站、社群媒體）不會將資料寫在 HTML 裡，而是透過背景發送 API 請求載入。與其用 BeautifulSoup 解析 HTML，不如直接抓取 API 回傳的 JSON 資料，這樣更快且更精準。

demo2_ajax_json.py
import requests

# 透過瀏覽器 F12 "Network" (網路) 面板，找出資料實際來源的 API 網址
api_url = "https://example.com/api/products"

# 有些 API 需要帶參數 (Query String)
params = {
    "category": "electronics",
    "limit": 10
}

response = requests.get(api_url, params=params)

if response.status_code == 200:
    # 直接將回傳的 JSON 轉換為 Python 的字典 (Dictionary) 或列表 (List)
    data = response.json()
    
    print(f"成功取得 {len(data['items'])} 筆產品資料：")
    for item in data['items']:
        print(f"品名: {item['name']}, 價格: {item['price']}")

Demo 3 檔案與圖片下載

爬蟲不只能抓文字，也能下載圖片或 PDF 檔案。這需要使用 response.content (二進位資料) 配合 Python 的檔案寫入操作。

demo3_download_file.py
import requests
import os

image_url = "https://example.com/images/sample.jpg"
# 準備儲存的檔名
filename = "downloaded_image.jpg"

print(f"開始下載圖片...")
response = requests.get(image_url)

if response.status_code == 200:
    # 開啟檔案，模式設定為 'wb' (Write Binary)
    with open(filename, "wb") as file:
        # 將二進位內容寫入檔案
        file.write(response.content)
    print(f"圖片已成功儲存為 {filename}")
else:
    print("下載失敗！")

Demo 4 保持登入狀態：使用 requests.Session

有些網頁必須登入後才能看。如果每次都用 requests.get()，伺服器會認為你是不同的未登入訪客。我們可以使用 Session 物件來自動記錄 Cookies。

demo4_session_login.py
import requests

login_url = "https://example.com/login"
target_data_url = "https://example.com/my-profile"

# 準備登入的帳號密碼資料 (根據目標網站的表單 name 屬性設定)
payload = {
    "username": "my_account",
    "password": "secret123"
}

# 建立一個 Session 實例，它會自動幫我們管理 Cookies
session = requests.Session()

# 1. 發送 POST 請求進行登入
print("嘗試登入...")
session.post(login_url, data=payload)

# 2. 使用同一個 session 發送 GET 請求抓取需要權限的網頁
response = session.get(target_data_url)

if "登出" in response.text: # 簡單驗證是否成功登入
    print("登入成功！已抓取受保護的資料。")
else:
    print("登入失敗。")

Demo 5 禮貌爬蟲與錯誤重試機制

網路環境不穩定，或是網站偶爾無回應。一個健壯的爬蟲程式碼需要具備「超時設定 (Timeout)」與「錯誤重試 (Retry)」的能力。

demo5_retry_and_timeout.py
import requests
import time

url = "https://example.com/unstable-page"
max_retries = 3

for attempt in range(max_retries):
    try:
        print(f"第 {attempt + 1} 次嘗試連線...")
        # timeout=5 代表如果 5 秒內伺服器沒回應，就主動放棄並觸發例外
        response = requests.get(url, timeout=5)
        
        # 如果狀態碼不是 200，會主動拋出 HTTPError
        response.raise_for_status() 
        
        print("抓取成功！")
        break # 成功就跳出迴圈
        
    except requests.exceptions.RequestException as e:
        print(f"發生錯誤：{e}")
        if attempt < max_retries - 1:
            print("等待 3 秒後重試...")
            time.sleep(3)
        else:
            print("已達最大重試次數，放棄抓取。")

Demo 6 神兵利器：使用 Pandas 秒抓 HTML 表格

如果你要抓的資料剛好是網頁上的 <table>（例如股票數據、匯率表），使用 pandas.read_html() 是最快的方法，它可以直接將 HTML 表格轉為 DataFrame，連 BeautifulSoup 都不用寫！

demo6_pandas_table.py
import pandas as pd

# 目標網址 (假設該網頁包含表格)
url = "https://example.com/stock-prices"

try:
    print("正在解析網頁表格...")
    # read_html 會回傳一個列表，包含網頁中「所有」找到的表格
    tables = pd.read_html(url)
    
    print(f"網頁中共找到 {len(tables)} 個表格。")
    
    # 假設我們需要的是第一個表格 (索引為 0)
    df = tables[0]
    
    # 印出表格前 5 筆資料
    print(df.head())
    
    # (加碼) 將抓到的資料直接存成 CSV 檔案
    df.to_csv("stock_prices.csv", index=False, encoding="utf-8-sig")
    print("資料已儲存為 stock_prices.csv")
    
except ValueError:
    print("在該網頁找不到任何 HTML 表格！")
