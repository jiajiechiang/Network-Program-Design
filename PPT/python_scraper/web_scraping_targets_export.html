4 大主題網站解析與 CSV/Excel 資料匯出

事前準備：
本教學將使用 requests, beautifulsoup4 以及 pandas。
匯出 Excel 需要額外安裝套件，請在終端機輸入：
pip install requests beautifulsoup4 pandas openpyxl

如何觀察網頁結構 (F12 開發者工具)

在開始寫程式前，觀察網頁結構是最重要的一步。每個網站的程式碼都不一樣，請依照以下步驟找出你要的資料：

  1. 在目標網頁上按鍵盤 F12 (或右鍵選擇「檢查」) 打開開發者工具。
  2. 點擊左上角的「元素選取器」(一個小箭頭的圖示)。
  3. 將滑鼠移動到你想抓取的資料上 (例如新聞標題、商品價格)，點擊下去。
  4. 右側的原始碼面板會亮起對應的 HTML 標籤。觀察它的 <標籤名稱> 與 class 或 id 屬性。
  5. 例如：看到 <h2 class="news-title">標題</h2>，你的程式碼就要寫 soup.find('h2', class_='news-title')。

主題 1 新聞網站 (News)

新聞網站通常結構比較靜態。重點在於找出「列表清單」的共同 class，抓取標題與文章連結。

1_news_scraper.py
import requests
from bs4 import BeautifulSoup

url = "https://example-news-website.com"
res = requests.get(url)
soup = BeautifulSoup(res.text, "html.parser")

news_list = []
# 假設新聞標題都放在 <h3 class="article-title"> 裡面的 <a> 標籤
articles = soup.find_all("h3", class_="article-title")

for article in articles:
    link_tag = article.find("a")
    if link_tag:
        title = link_tag.text.strip()
        link = link_tag.get("href")
        news_list.append({"標題": title, "連結": link})

print(news_list)

主題 2 電商網站 (E-commerce)

電商網站的重點是抓取商品名稱與價格。注意：很多大型電商 (如 Shopee, PChome) 是動態載入的，如果用 BeautifulSoup 抓不到，需要改用 F12 的「Network」面板找 JSON API。

2_ecommerce_scraper.py
import requests
from bs4 import BeautifulSoup

url = "https://example-ecommerce.com/category/laptops"
res = requests.get(url)
soup = BeautifulSoup(res.text, "html.parser")

products_data = []
# 假設每個商品被包在 <div class="product-item">
items = soup.find_all("div", class_="product-item")

for item in items:
    # 尋找名稱與價格的特徵標籤
    name = item.find("div", class_="prod-name").text.strip()
    price = item.find("span", class_="price-val").text.strip()
    products_data.append({"商品名稱": name, "價格": price})

print(products_data)

主題 3 氣象網站 (Weather)

氣象網站通常會有明確的區塊顯示各地的溫度與降雨機率。也可以直接利用中央氣象署的公開 API (JSON) 來抓取會更精準。

3_weather_scraper.py
import requests
from bs4 import BeautifulSoup

url = "https://example-weather.com/taiwan"
res = requests.get(url)
soup = BeautifulSoup(res.text, "html.parser")

weather_list = []
# 假設每筆天氣資訊在 <div class="city-weather"> 中
cities = soup.find_all("div", class_="city-weather")

for city in cities:
    city_name = city.find("h4").text.strip()
    temp = city.find("div", class_="temperature").text.strip()
    rain_prob = city.find("span", class_="rain").text.strip()
    
    weather_list.append({
        "城市": city_name, 
        "溫度": temp, 
        "降雨機率": rain_prob
    })

主題 4 股票網站 (Stocks)

股票資料通常以「表格 (Table)」呈現。這時候我們可以直接使用強大的 pandas.read_html()，它可以一秒將網頁上的 <table> 轉為資料表，省去寫 BeautifulSoup 的麻煩。

4_stock_scraper.py
import pandas as pd

url = "https://example-stock-market.com/daily-quotes"

try:
    # read_html 會找尋網頁中所有的 <table>，回傳一個 List
    dfs = pd.read_html(url)
    
    # 假設我們要的股票數據在網頁的第一個表格裡
    stock_df = dfs[0]
    
    print("股票資料抓取成功！前 5 筆如下：")
    print(stock_df.head())
    
except Exception as e:
    print("抓取表格失敗：", e)

終極應用 將資料存成 CSV 與 Excel 檔案

不論你抓的是新聞、電商還是天氣，最後我們都會將資料整理成 Python 的 List of Dictionaries (字典列表)。接著只要交給 pandas，兩行程式碼就能匯出檔案！

5_export_data.py
import pandas as pd

# 這是我們剛剛抓到的資料 (以電商為例)
data = [
    {"商品名稱": "電競筆電 A", "價格": "35,000"},
    {"商品名稱": "無線滑鼠 B", "價格": "990"},
    {"商品名稱": "機械鍵盤 C", "價格": "2,500"}
]

# 1. 將資料轉換為 Pandas 的 DataFrame 表格結構
df = pd.DataFrame(data)

# 2. 儲存成 CSV 檔案
# index=False 代表不要輸出左側的 0,1,2 數字索引
# encoding='utf-8-sig' 確保用 Excel 打開 CSV 時中文不會亂碼
df.to_csv("ecommerce_products.csv", index=False, encoding='utf-8-sig')
print("CSV 儲存成功！")

# 3. 儲存成 Excel 檔案 (.xlsx)
# 注意：需要安裝 openpyxl 套件 (pip install openpyxl)
df.to_excel("ecommerce_products.xlsx", index=False)
print("Excel 儲存成功！")
