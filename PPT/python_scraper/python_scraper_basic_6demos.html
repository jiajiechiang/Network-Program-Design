爬蟲開發環境準備：
網路爬蟲的核心是「取得網頁」與「解析資料」。我們將使用最主流的兩個套件。請在終端機輸入以下指令進行安裝：

pip install requests beautifulsoup4

Demo 1 基礎請求：取得網頁原始碼 (requests)

爬蟲的第一步，就是模擬瀏覽器發送 HTTP 請求給網站，並把 HTML 原始碼抓下來。

demo1_get_html.py
import requests

# 1. 指定要抓取的網址 URL
url = "https://example.com"

# 2. 發送 GET 請求
response = requests.get(url)

# 3. 檢查狀態碼 (200 代表成功，404 代表找不到，403 代表被拒絕)
print("狀態碼：", response.status_code)

# 4. 印出抓取到的 HTML 文字內容 (這裡只印出前 100 個字元)
if response.status_code == 200:
    print(response.text[:100])

Demo 2 解析 HTML：BeautifulSoup 初體驗

抓下來的 response.text 是一大串難以閱讀的字串。我們需要 BeautifulSoup 將它轉換為可以輕鬆尋找標籤的結構化物件。

demo2_beautifulsoup.py
import requests
from bs4 import BeautifulSoup

url = "https://example.com"
response = requests.get(url)

# 將 HTML 字串交給 BeautifulSoup 解析，使用 'html.parser' 解析器
soup = BeautifulSoup(response.text, "html.parser")

# 輕鬆取得網頁標題 <title>
print("網頁標題標籤：", soup.title)
# 只取出標題的「純文字」部分
print("純文字標題：", soup.title.text)

Demo 3 尋找元素：find 與 find_all

在解析完的 HTML 中，最常用的兩個指令是：
find()：尋找符合條件的第一個元素。
find_all()：尋找符合條件的所有元素，並回傳一個列表 (List)。

demo3_find_elements.py
from bs4 import BeautifulSoup

# 我們準備一段測試用的 HTML 假資料
html_doc = """
<html>
    <body>
        <h1 class="main-title">今日新聞</h1>
        <p class="news">第一條新聞內容...</p>
        <p class="news">第二條新聞內容...</p>
    </body>
</html>
"""
soup = BeautifulSoup(html_doc, "html.parser")

# 尋找第一個 <h1> 標籤
h1_tag = soup.find("h1")
print("H1 文字：", h1_tag.text)

# 尋找所有 class 為 'news' 的 <p> 標籤 (注意：Python 中 class 是保留字，所以參數要加底線 class_)
news_paragraphs = soup.find_all("p", class_="news")

print("共找到幾條新聞：", len(news_paragraphs))
for news in news_paragraphs:
    print("-", news.text)

Demo 4 擷取屬性：取得連結 (href) 與圖片 (src)

除了標籤內的文字，我們經常需要抓取標籤的屬性（Attribute），例如 <a> 標籤裡的網址，或是 <img> 裡的圖片來源。

demo4_get_attributes.py
from bs4 import BeautifulSoup

html_doc = """
<div class="links">
    <a href="https://google.com" id="link1">前往 Google</a>
    <img src="cat.jpg" alt="可愛貓咪">
</div>
"""
soup = BeautifulSoup(html_doc, "html.parser")

# 1. 取得超連結網址
a_tag = soup.find("a")
# 像操作字典一樣，使用 ['屬性名稱'] 或 .get('屬性名稱') 取出屬性值
link_url = a_tag.get("href") 
print("抓取到的網址：", link_url)

# 2. 取得圖片來源
img_tag = soup.find("img")
image_src = img_tag["src"]
print("圖片檔案來源：", image_src)

Demo 5 偽裝瀏覽器：設定 User-Agent

許多網站為了防止爬蟲，會檢查請求是否來自正常的瀏覽器。如果沒有設定 User-Agent，你的請求可能會被拒絕 (回傳 403 Forbidden)。

demo5_user_agent.py
import requests

url = "https://www.ptt.cc/bbs/Stock/index.html" # 以 PTT 為例

# 設定 Headers，偽裝成一般的 Google Chrome 瀏覽器
headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36"
}

# 發送請求時，將 headers 參數帶入
response = requests.get(url, headers=headers)

if response.status_code == 200:
    print("成功突破防護，抓取成功！")
else:
    print("抓取失敗，狀態碼：", response.status_code)

Demo 6 實戰演練：抓取清單並結構化輸出

將前五個 Demo 結合！假設我們抓取了一個部落格首頁，我們要把所有的文章標題與連結抓出來，並整理成結構化的資料。

demo6_practical_scraping.py
from bs4 import BeautifulSoup

# 模擬抓取到的部落格 HTML
html_source = """
<ul class="article-list">
    <li class="item">
        <h3><a href="/post/1">Python 入門教學</a></h3>
        <span class="date">2024-01-01</span>
    </li>
    <li class="item">
        <h3><a href="/post/2">爬蟲實戰指南</a></h3>
        <span class="date">2024-01-05</span>
    </li>
</ul>
"""

soup = BeautifulSoup(html_source, "html.parser")

# 建立一個空的列表，用來儲存整理好的資料
scraped_data = []

# 1. 找到所有 class 為 'item' 的區塊 (<li>)
articles = soup.find_all("li", class_="item")

# 2. 針對每一篇文章區塊，提取我們想要的資訊
for article in articles:
    # 在縮小的 article 範圍內，尋找 <a> 和 <span>
    title_tag = article.find("a")
    date_tag = article.find("span", class_="date")
    
    # 整理成字典 (Dictionary)
    item_info = {
        "標題": title_tag.text,
        "連結": "https://myblog.com" + title_tag["href"], # 組合完整網址
        "日期": date_tag.text
    }
    scraped_data.append(item_info)

# 3. 印出最終結果
for data in scraped_data:
    print(data)
